# 외눈 다족 몬스터 애니메이션 시트 가이드

## 파일 규격

각 시트는 다음 규격으로 고정되어 있습니다.

- 전체 이미지: **2048 × 512 px**
- 프레임 배열: **8열 × 2행**
- 개별 프레임: **256 × 256 px**
- 색상 모드: **RGBA / 투명 배경**
- 프레임 내부 안전 영역: 캐릭터 최대 약 200px, 셀 가장자리에서 약 28px 이상 여백
- 셀 사이 간격: 없음
- 원점: 이미지 좌상단

## 제공 파일

- `monster-crawler-anim-v1.5.2.png`
- `monster-spitter-anim-v1.5.2.png`
- `monster-brood-beast-anim-v1.5.2.png`

## 애니메이션 구성 권장값

### 이동

프레임 01–06을 순환 재생합니다.

- 권장 속도: 10–12 FPS
- 루프: 01 → 02 → 03 → 04 → 05 → 06 → 01
- 이동 속도가 빠른 적은 14–16 FPS까지 올립니다.
- 프레임 13–16은 더 크게 다리를 들어 올린 동작이므로 돌진, 가속, 공격 전 이동에 사용합니다.

### 대기

프레임 07–08을 2–4 FPS로 천천히 교차 재생합니다. 몸통의 미세한 상하 움직임을 표현하는 용도입니다.

### 깜빡임

프레임 09–12를 한 번 재생합니다.

- 권장 재생: 09 → 10 → 11 → 12
- 권장 시간: 전체 0.18–0.25초
- 반복 주기: 약 2–5초마다 무작위 실행
- 이동 루프와 동시에 재생할 때는 눈 영역만 교체하고 다리 프레임은 현재 이동 프레임을 유지하는 방식이 가장 자연스럽습니다.

## Unity에서 사용하는 경우

1. Texture Type을 `Sprite (2D and UI)`로 설정합니다.
2. Sprite Mode를 `Multiple`로 설정합니다.
3. Sprite Editor에서 Grid By Cell Size를 선택합니다.
4. Cell Size를 `256 × 256`으로 입력합니다.
5. Slice 후 프레임을 좌상단부터 순서대로 이름 붙입니다.
6. Filter Mode는 픽셀 아트가 아니라면 `Bilinear`, 선명한 캐주얼 일러스트를 유지하려면 `Bilinear`와 적절한 압축 해제를 권장합니다.
7. Pivot은 모든 프레임에서 `Center`를 사용합니다. 그림자까지 포함한 중앙 정렬이 필요하면 Custom Pivot을 `(0.5, 0.5)`로 고정합니다.

## 일반 이미지 처리 코드 기준

```text
for row in 0..1:
    for col in 0..7:
        x = col * 256
        y = row * 256
        crop = sheet[x:x+256, y:y+256]
```

## 크롭 시 주의사항

- 256px 셀 경계를 임의로 줄이거나 늘리지 않습니다.
- 가장자리의 투명 여백을 제거하는 Trim/Crop 옵션은 사용하지 않습니다.
- 프레임별 자동 Trim을 적용하면 피벗이 흔들리고 다리의 움직임이 튀어 보일 수 있습니다.
- 모든 프레임을 동일한 256×256 셀로 유지해야 합니다.
- 원본 시트의 체커보드처럼 보이는 배경은 실제 배경이 아니라 투명 영역입니다.
