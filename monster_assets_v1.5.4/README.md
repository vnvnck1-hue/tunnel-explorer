# Monster Assets v1.5.4

게임에 연결된 최종 몬스터 리소스와 제작 이력을 한 폴더에 모아둔 디렉터리입니다.

- `frames/crawler/` — Crawler 최종 누끼 프레임 16장
- `frames/spitter/` — Spitter 최종 누끼 프레임 16장
- `frames/brood-beast/` — Brood Beast 최종 누끼 프레임 16장
- `sheets/` — 생성·보정 단계별 원본 애니메이션 시트
- `concepts/` — 몬스터 콘셉트 이미지 버전별 보관
- `docs/` — 크롭 좌표와 애니메이션 사용 가이드
- `tools/` — 시트 생성·크롭·그림자 제거 스크립트
- `frames/archive/` — 이전 크롭 버전 보관

게임 파일 `tunnel-crew-infinite-mode-v7.1.3.html`은 `frames/crawler`, `frames/spitter`, `frames/brood-beast`의 v1.5.4 프레임을 직접 로드합니다.
