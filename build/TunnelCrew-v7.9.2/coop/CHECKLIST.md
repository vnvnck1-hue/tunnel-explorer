# 멀티플레이 안정성 체크리스트 (누적)

수시로 반복하는 코옵 안정성 검증의 기준 문서.
새 게임 버전이 나오거나, coop 서버/클라이언트를 고치거나, 이상 징후가 보이면 실행한다.
실행 후 맨 아래 **누적 기록**에 한 줄(또는 한 섹션)을 추가한다 — 지우지 말 것.

> 실행 방법: Claude 에게 이 문서를 기준으로 "코옵 체크리스트 돌려줘"라고 요청하면
> 브라우저 두 탭으로 A–J 를 자동 검증한다. 사람 손 테스트(M 항목)는 실기기 2대 이상.

## 검증 전 필수 확인 (자동화 함정 — 실제로 겪은 것들)

- [ ] 서버가 **최신 코드로 재시작**됐는가 (릴레이 타입 추가 후 구서버가 조용히 메시지를 버림)
- [ ] 테스트 탭이 **force 리로드**됐는가 (같은 URL navigate 는 no-op — 옛 코드로 측정하게 됨)
- [ ] 참가는 **방 코드 명시**로 (목록 첫 버튼은 이전 런의 유예(ghost) 방일 수 있음)
- [ ] **A_setup 를 먼저 확인**하고 나머지를 진행 (셋업 무효면 전체 결과가 무효)

## A–J 자동 배터리 (매 버전)

| # | 항목 | 통과 기준 |
|---|---|---|
| A | 셋업 성립 | 양쪽 seat/auth(host·guest)/_started/INF.active/동일 seed |
| B | 적 스냅샷 | 호스트 스폰 N마리 = 게스트 퍼펫 N마리, 광란종(apex) 플래그 동기 |
| C | 공격 위임(ehit) | 게스트 40 피해 → 호스트 hp 정확히 40 감소 |
| D | 킬 XP 귀속(ekill) | 게스트 킬 → 게스트 XP 증가 + **호스트 xpLog 비어 있음** + 퍼펫 제거 |
| E | 피어 타게팅/피격 | 적이 가까운 피어를 타깃(AI_TGT) + 접촉 피해가 phit 로 게스트 HP 감소 |
| F | 지형 diff | 호스트 셀 파괴/생성 → 게스트 반영 (5Hz 이내) |
| G | 보스 흐름 | 스폰→게스트 퍼펫(티어 동기)→처치→양쪽 휴식 모달+동일 코어 보상. **v7.7.2+: 협곡 돌진 벽 큐 생성 확인** |
| H | 하강 동기+가드 | 호스트 하강 → 게스트 자동 하강+모달 닫힘, 게스트 직후 클릭이 **층을 안 올림**(double descend 차단) |
| I | 탈출 게이트 | afk/무응답/연결 끊김 크루 제외 시 탈출 성립, 복귀 시 다시 대기 |
| J | 재접속 | 게스트 ws 강제 종료 → 자동 재접속(좌석 유지, reconTimer 정리) + 호스트 dropped 해제 |
| - | 콘솔 | 양 탭 에러 0 (meta 404 미스는 정상) |

## K. 서버 학대 (프로토콜 변경 시)

- [ ] 기형 패킷: 비JSON · 미지 타입 · 빈 객체 · 방 없는 start/role · 300KB 쓰레기 → 서버 생존
- [ ] 방 폭주: host+끊기 15회 → 방 잔량 0 (누수 없음)
- [ ] 만석 경쟁: 1방에 동시 참가 5 → 정확히 3석 배정 + 나머지 "가득" 거절
- [ ] 승계 체인: p1 로비 이탈 → 승계 + 승계자 모드 변경 권한
- [ ] 미지 pid resume → resume_fail
- [ ] 구버전 클라(v 불일치) host/join → "새로고침" 에러
- [ ] 비밀번호: 잠금 표시 · 오답 거절 · 정답 입장
- [ ] 탈출 경합: 늦은 요청자에게 기존 포트 회신, 타 크루 미전파
- [ ] 존재하지 않는 eid 공격 무해 · ehit 스팸 500발에도 서버/호스트 생존+피해 정밀

## L. 돌발 시나리오 (분기마다 또는 큰 변경 시)

- [ ] 호스트 런 중 사망 → 게스트 로컬 폴백 + 게임 지속 + 상호 다운 표시
- [ ] 호스트 순단 → 게스트 로컬 폴백 → 호스트 복귀 → 권위 재동기화(퍼펫 재구축)
- [ ] 재접속 크루 지형 치유 (드리프트 셀이 호스트 값으로 복구)
- [ ] 층 어긋남 중 이전 층 esnap → 유령 퍼펫 0 (dep 태그)
- [ ] 게스트 사망 후 도착하는 esnap/phit 무해
- [ ] 같은 브라우저 두 탭(같은 pid) 순차 순단 → 퇴장 방송 중복 없음

## M. 실기기 수동 테스트 (사내 배포 전 / 월 1회)

- [ ] 실제 PC 2~4대, `http://<서버IP>:5188/` 접속, 방 목록으로 합류
- [ ] 10분 이상 실플레이: 움직임 부드러움(외삽), 적 위치 일치 체감, 벽 파괴 동기
- [ ] 보스전: 패턴이 여러 크루에게 분산되는지, 협곡/감옥이 남의 머리 위에도 떨어지는지
- [ ] 알트탭/최소화 → 남은 크루 탈출 가능, 복귀 시 정상 합류
- [ ] Wi-Fi 껐다 켜기(순단) → 자동 재접속
- [ ] 노드 트리: 닉네임 동일하게 다른 PC 접속 → 성장 이어짐

## 알려진 한계 (실패 아님 — 재확인만)

- 게스트 시간정지·상태이상 유물은 호스트 적에 안 걸림
- 호스트 유물이 게스트 적중에도 발동
- 게스트 보스탄 피해에 크루 경감 중복(약간 유리)
