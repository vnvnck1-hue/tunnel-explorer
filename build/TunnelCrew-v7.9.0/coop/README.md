# 사내 코옵 (인트라넷 · 2~4인)

회사 네트워크의 PC 한 대에서 서버를 돌리고, 나머지는 브라우저로 접속해 함께 플레이합니다.
"호스트가 된다" = 게임 안에서 방을 만드는 것(p1 좌석). 서버 실행과는 무관합니다.

## 서버 (사내망 PC 아무거나 한 대)

```bash
cd coop
npm install
npm start
```

터미널에 나오는 `사내망: http://<IP>:5188/` 주소를 팀에 공유합니다.
`/` 로 접속하면 곧바로 본편(v7.7.1)이 열립니다. Windows 방화벽이 Node.js 를 물으면
**개인/회사 네트워크 허용**. 다른 버전을 열려면 환경변수 `GAME=/파일명.html`.

> **고정 IP 권장**: DHCP 로 서버 PC 의 IP 가 바뀌면 접속 주소가 바뀝니다.
> IT팀에 고정 IP(또는 사내 호스트네임)를 요청해 두는 것이 가장 깔끔합니다.
> 성장 데이터는 서버가 닉네임 키로 보관하므로(아래) 주소가 바뀌어도 이어집니다.

> 폴더 구조 주의: 실체는 `<루트>/coop` 이고 `claude-work/coop` 은 정션입니다.
> ESM `__dirname` 은 실제 경로로 풀리므로 서버 정적 루트는 `..` 한 단계(저장소 루트)입니다.

## 플레이 순서 (v4)

1. 브라우저로 `http://<서버IP>:5188/` 접속 → 메인 메뉴 → **LAN 코옵**
2. **닉네임** 입력 — 닉네임이 곧 계정입니다 (성장 데이터 서버 동기화 키)
3. **방 만들기** (방 이름·비밀번호 선택) — 방은 목록에 자동 공개됩니다
   또는 **방 목록**에서 [참가] 클릭 (🔒 방은 비밀번호 입력)
4. 각자 **역할** 선택 → 호스트(👑 P1)가 **미션 시작**
5. 같은 시드의 맵에서 함께 채굴·전투·탈출. 각자의 경험치·카드·코어는 개인 성장(§5.2).

## v4 에서 해결된 5가지 (사내 테스트 대비)

1. **적·보스 호스트 권위 동기화** — 적 스폰·AI·보스 패턴을 호스트(p1)가 시뮬레이션하고
   15Hz 스냅샷 + 5Hz 지형 diff(보스 벽 소환·암반 장갑·돌진 붕괴)로 전파.
   게스트 공격은 ehit 위임, 처치 기여자에게 ekill 로 경험치 귀속(§5.2 유지).
   피어도 적 타깃이 되고(AI_TGT 확장) 피격은 phit 로 각자 판정.
   호스트가 나가면 남은 크루는 자동으로 로컬 시뮬레이션 폴백, 복귀하면 재동기화.
2. **탈출 교착 방지** — 탭 백그라운드(자리 비움)·10초 무응답 크루는
   "생존자 전원 탑승" 판정에서 자동 제외. 돌아오면 다시 포함. 명판에 상태 표시.
3. **자동 재접속** — 진행 중 런에서 연결이 끊기면(순단·절전) 좌석을 60초 보존하고
   2초 간격으로 재접속해 좌석·역할 그대로 복귀. 실패하면 솔로로 이어서 진행.
4. **성장 데이터 서버 보관** — INF_META(노드 트리·보관 코어·기록)를 서버가
   닉네임 키로 보관(`coop/saves/`), 저장 시각이 최신인 쪽을 채택.
   localhost ↔ IP ↔ 주소 변경에도 성장이 이어집니다. file:// 솔로는 로컬 저장 그대로.
5. **자잘한 것** — 탈출 포트 동시 요청은 서버가 중재(먼저 온 요청 승리, 5초 창)
   · 프로토콜 버전 체크(낡은 탭 → "새로고침 하세요") · 방 비밀번호(선택).
