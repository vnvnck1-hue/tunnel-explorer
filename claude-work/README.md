# claude-work — 특성 카드 레이아웃 작업 폴더

`tunnel-crew-infinite-mode-v7.1.4.html` 을 복제한 **v7.1.5** 작업본과, 카드 레이아웃을
눈으로 맞춰서 게임에 반영하기 위한 도구들이 들어 있습니다.

`assets/`, `coop/`, `monster_assets_v1.5.4/`, `tiles/`, `tunnel_crew_tile_resources_v1/`
는 상위 폴더를 가리키는 **디렉터리 정션**입니다. 원본을 복사하지 않으므로 상대 경로가
그대로 동작하고, 여기서 자산을 지워도 원본에 영향이 없습니다(정션 자체를 지울 때는
`rmdir` 로 링크만 지우세요).

## 작업 흐름

```bash
python -m http.server 8777
```

1. **배치한다** — <http://127.0.0.1:8777/trait-card-layout-editor.html>
   등급 탭을 고르고 레이어를 드래그·리사이즈, 오른쪽에서 글자 크기·색·정렬을 조절합니다.
   `전체 보기` 로 그 등급의 특성 전부를, `이 등급 검사` / `전체 등급 검사` 로 글자가
   넘치는 특성이 있는지 확인합니다. 작업 내용은 브라우저에 자동 저장됩니다.
2. **내보낸다** — `내보내기` → `파일로 저장`. `trait-card-layout.json` 이 받아집니다.
   이 폴더에 덮어쓰면 됩니다.
3. **반영한다**
   ```bash
   python tools/apply_trait_card_layout.py trait-card-layout.json
   ```
4. **확인한다** — 게임을 열어보거나
   ```bash
   python tools/render_trait_card_preview.py trait-card-preview.png --guides
   ```

## 좌표계 — 편집기 값이 왜 그대로 CSS 로 안 들어가는가

편집기는 **카드 아트 이미지 기준 %** 로 다룹니다. 화면에서 보이는 그대로입니다.

게임에서는 이 레이어들이 `.infCardDepth` 안에 있고, 여기에 `perspective(850px)` 이
`50%/54%` 원점으로 걸려 있습니다. 레이어마다 `translateZ` 가 달라서 (아이콘 38px,
텍스트 28px) 화면상 `850/(850-z)` 배로 확대되는데, 정작 프레임 이미지는 z=0 이라
`scale(1.008)` 만 받습니다. 그래서 아트에서 잰 값을 CSS 에 그대로 넣으면 어긋납니다.

`apply_trait_card_layout.py` 가 위치와 **글자 크기** 양쪽에서 이 확대율을 역산해
넣습니다. 결과는 브라우저 실측으로 오차 0.2% 이내입니다.

글자 크기는 **카드 폭 250px 기준 px** 입니다. 게임 CSS 는 이를 `cqw` 로 환산하므로
레벨업 카드(250px)든 심층 보상 카드(210px)든 같은 비율로 보입니다. 등급별로 따로
크기를 잡을 필요가 없습니다.

### 반영 스크립트가 자동으로 손보는 것

편집기 화면과 게임 화면을 맞추기 위해 다음 두 가지를 자동 처리하고, 실행할 때
무엇을 고쳤는지 `note:` 로 알려줍니다.

- **아이콘 위에 올린 텍스트** — `.infCardDepth` 는 `preserve-3d` 라서 형제 요소가
  z-index 가 아니라 **깊이 순서**로 그려집니다. 아이콘이 `translateZ(38px)` 라
  그냥 두면 텍스트가 아이콘에 가립니다. 편집기는 평면이라 텍스트가 위로 보이므로,
  아이콘 창과 겹치는 텍스트 레이어는 `translateZ(44px)` 로 올려 편집기와 맞춥니다.
  JSON 레이어에 `"z": 44` 처럼 직접 지정하면 그 값을 씁니다.
- **`#` 빠진 색값** — 편집기의 색 입력은 자유 입력이라 `ffffff` 처럼 쓰기 쉽습니다.
  그대로면 CSS 에서 무효한 색이 되므로 `#ffffff` 로 보정합니다.
- **자간의 끝 여백** — `letter-spacing` 은 마지막 글자 뒤에도 공백을 넣습니다. 가운데
  정렬이면 보이는 글자가 그 절반만큼 왼쪽으로 밀리므로 (등급 명판 0.13em → 22px 에서
  1.4px) 되돌립니다. 편집기 미리보기도 같은 보정을 합니다.

### 등급 명판은 왜 아래로 내려와 보였나

명판의 **안쪽 면**(글자 들어가는 색면) 기준으로는 정확히 가운데였습니다 — 실측 오차
0.4px 이내. 그런데 아트에서 명판 **위쪽 베벨이 넓고 밝고 아래쪽은 얇아서**, 눈은
베벨까지 포함한 명판 전체를 보고 중앙을 판단합니다. 그래서 안쪽 면 기준 중앙은
아래로 내려와 보입니다.

지금은 명판 **실루엣**(베벨 포함) 중앙에 글자의 잉크 박스를 맞춰 놓았습니다. 등급별로
위로 올린 양은 일반 0.70%, 희귀 0.25%, 영웅 0.16%, 전설 0.42% (카드 높이 기준)입니다.
더 조절하고 싶으면 편집기에서 명판 레이어를 위아래로 옮기면 됩니다.

## 도구

| 파일 | 하는 일 |
|---|---|
| `trait-card-layout-editor.html` | 레이아웃 편집기. JSON 입출력 |
| `trait-sample-data.json` | 편집기가 쓰는 실제 특성 38개 (이름·분류·설명·아이콘) |
| `trait-card-layout.json` | 현재 적용된 레이아웃 |
| `tools/apply_trait_card_layout.py` | JSON → 게임 HTML (원근 보정 포함) |
| `tools/render_trait_card_preview.py` | JSON 으로 카드 이미지 렌더 (등급별 최장 텍스트 샘플) |
| `tools/measure_trait_card_geometry.py` | 카드/아이콘 PNG 실측 → 편집기 `REF`, `INF_TRAIT_ICON_FIT` |

카드 프레임이나 아이콘을 다시 뽑았을 때만 `measure_trait_card_geometry.py` 를
돌리고, 출력한 두 블록을 안내대로 붙여넣으면 됩니다.

## 카드 구성 (v7.1.5)

| 레이어 | 자리 | 내용 |
|---|---|---|
| `tier` | 상단 명판 | 등급 이름 |
| `icon` | 원형 창 | 특성 아이콘 |
| `name` | 아이콘 아래 어두운 바 | **특성 이름** |
| `kind` | 하단 판 위쪽 | 분류 (역할 · 계열) |
| `desc` | 하단 판 | 특성 설명 |

각 텍스트 레이어는 자기 기준 크기에서 자기 하한까지만 자동으로 줄어듭니다
(`--<키>-fs` / `--<키>-min`). 편집기의 미리보기와 같은 규칙입니다.
