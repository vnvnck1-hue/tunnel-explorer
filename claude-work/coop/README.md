# LAN 코옵 (집 Wi‑Fi · Windows + Mac)

각자 PC에서 브라우저로 접속해 2인 코옵을 테스트합니다.

## 호스트 (윈도우 PC)

```bash
cd coop
npm install
npm start
```

터미널에 나오는 주소를 확인합니다.

- 본인: `http://127.0.0.1:5188/demos/tunnel-crew-loop-demo.html`
- 와이프(맥): `http://192.168.x.x:5188/demos/tunnel-crew-loop-demo.html`  ← LAN 줄

Windows 방화벽이 Node.js를 물으면 **개인 네트워크 허용**.

## 플레이 순서

1. 메인 메뉴에서 **LAN 코옵 (테스트)** 선택  
2. **호스트** → **방 만들기** → 4자리 코드 확인  
3. **게스트(맥)** → 코드 입력 → **참가**  
4. 각자 **역할** 선택 (다른 역할 권장: 드릴러 + 스카웃 등)  
5. 호스트만 **미션 시작** 클릭  
6. 같은 맵에서 이동·채굴·탈출

솔로는 메인 메뉴 **솔로 미션**. 코옵 로비에서 **메인 메뉴**로 돌아갈 수 있습니다.

## v2 (트랙 F) — 2~4인 · 본편 무한 모드 지원

- 방 최대 **4인** (좌석 p1~p4, p1 = 호스트)
- 호스트가 모드 선택: **채취 미션** / **무한 모드 (본편)**
- 본편 코옵으로 열려면 같은 포트에서 게임 HTML을 연다:
  `http://<호스트IP>:5188/tunnel-crew-infinite-mode-v7.3.0.html`
