# 땅굴 크루 실시간 특성 노드 시스템

> 상태: **v0.2 전체 기획 확정 · 구현 보류 · 효과 및 수치 검증 전**
> 최종 갱신: 2026-08-27  
> 1차 적용 범위: **무한 모드의 런 전용 성장**  
> 기준 구현: tunnel-crew-infinite-mode-v7.1.7.html

이 문서는 특성 노드 시스템의 **누적형 단일 기준 문서**다. v0.2는 기존 휴식 화면 전용 15노드 시안을 대체하며, 채굴 중 언제든 열고 성장시키는 점진 공개형 트리를 기준으로 한다.

## 0. 핵심 결정

- 특성 창은 키보드 왼쪽의 **Tab 키**로 언제든 연다.
- 특성 포인트를 없애고, 채굴로 얻는 **펄프·블룸·암반 코어**를 노드에 직접 소비한다.
- 처음에는 중앙 코어와 구매 가능한 노드 4개만 보인다. 구매하면 연결된 인접 노드만 새로 드러난다.
- 트리는 **공용 기초 18개 + 현재 직업 전용 36개**, 총 54개 구매 노드로 구성한다.
- 드릴러·거너·스카우트·엔지니어는 각각 별도의 36노드 트리를 가진다.
- 30분 기준 16~20개, 전용 캡스톤 1개 완성을 목표로 하며 한 런에 전체 구매는 불가능하다.
- 일반 노드는 펄프, 중간 노드는 펄프+블룸, 핵심 노드는 펄프+블룸+코어를 함께 요구한다.
- 구매는 실시간으로 허용하되 전투 중 무제한 갈아끼우기는 막는다.
- 레벨업 카드·보스 보상·특성 노드가 같은 행동 변형을 중복 제공하지 않게 역할을 나눈다.

## 1. 문서 운영과 변경 기록

상태는 **확정, 검증 중, 보류, 폐기**로 표시한다. 구조와 플레이 방식이 확정돼도 피해량·지속시간·비용은 실제 테스트 전까지 1차 수치다. 결정을 바꿀 때는 내용을 조용히 덮지 않고 변경 이유를 남긴다.

### 2026-08-27 · v0.1

- 직업·스킬 단위 소형 변형 트리를 분석했다.
- 드릴러를 굴진 과급·균열 공학·돌파 파기의 3분기 15노드로 설계했다.
- 보스 처치 특성 포인트와 휴식 화면 구매를 사용했다.

### 2026-08-27 · v0.2 개편

- **폐기:** 보스당 특성 포인트 1점, 휴식 화면에서만 구매, 시작부터 15개 전체 공개.
- **폐기:** 모든 직업이 15개 노드만 가지는 소형 고정 트리.
- **확정:** 채굴 재화 직접 소비, Tab 실시간 접근, 인접 노드 점진 공개.
- **확정:** 공용 18개와 직업별 전용 36개를 결합한 54노드 그래프.
- **유지:** 수치 세금 최소화, 행동 변형 중심, 한 런 전체 획득 불가, 저비용 초기화.

### 2.2 반복해서 나타나는 좋은 흐름

1. 행동 변형의 밀도가 노드 수보다 중요하다.
2. 초반 선택지를 작게 보여주고 숙련도에 맞춰 복잡도를 공개한다.
3. 범용 기초와 직업 정체성을 같은 길목에 몰아넣지 않는다.
4. 끝 노드는 조작·리스크·화면을 동시에 바꾼다.
5. 한 런에서 전부 찍지 못해야 빌드를 한 문장으로 설명할 수 있다.
6. 초기화 비용은 낮추되 전투마다 즉시 갈아끼우는 최적화는 막는다.
7. 희귀 자원은 명확한 성장 목표와 연결될 때 채굴 경로 선택을 만든다.

### 2.3 피해야 할 패턴

- 체감 없는 피해량 +3% 노드를 연속 구매하는 수치 세금
- 멀리 보인 캡스톤으로 가는 실제 길은 막혀 있는 구조
- 희귀 노드 앞의 단일 강제 경로
- 시작부터 50개 이상의 툴팁을 보여주는 정보 과부하
- 안개가 정보만 숨기고 발견 보상이나 방향 힌트를 주지 않는 구조
- 모든 직업이 공용 생존·화력부터 완성해 후반 역할이 같아지는 구조
- 희귀 재화를 초기화 비용으로 소각해 실험을 처벌하는 구조
- 랜덤 카드·보스 전설·특성 노드의 효과 중복

## 3. 목표 플레이 경험

> 벽을 파서 성장 재료를 얻고, Tab을 눌러 방금 발견한 자원으로 인접 회로를 가동한 뒤, 새로 드러난 노드를 목표로 다시 깊이 파고든다.

### 3.1 30초 단위 반복

1. 일반 암반을 파괴해 펄프 정제 게이지를 채운다.
2. 광맥의 색과 음향을 보고 블룸 또는 코어층 쪽으로 경로를 바꾼다.
3. 구매 가능 노드가 생기면 HUD의 Tab 아이콘이 맥동한다.
4. 안전한 틈 또는 짧은 위험을 감수하고 트리를 연다.
5. 노드 구매 시 연결선이 점등되고 인접 노드가 지층에서 솟아오르듯 공개된다.
6. 새 효과를 바로 채굴·전투에서 시험한다.

### 3.2 감정 곡선

| 시점 | 보여줄 것 | 기대 감정 |
|---|---|---|
| 시작 | 중앙 코어 + 4개 선택지 | 부담 없는 첫 방향 |
| 1~3분 | 첫 전용 분기와 공용 가지 | 내가 지도를 열고 있다는 감각 |
| 5~10분 | 블룸 노드와 교차로 | 희귀 광맥을 찾을 이유 |
| 10~20분 | 코어 노드의 윤곽과 대체 경로 | 이번 런 정체성 결정 |
| 20~30분 | 첫 캡스톤 | 플레이 방식과 화면이 바뀌는 절정 |
| 이후 | 두 번째 분기 또는 공용 보완 | 약점 보정과 장기 목표 |

## 4. 성장 재화 경제

### 4.1 재화는 세 종류만 사용

| 재화 | 획득처 | 주요 용도 |
|---|---|---|
| **펄프** pulp | 일반 암반 파쇄량 누적 시 자동 정제 | 공용 기초, 전용 초반, 모든 상위 노드의 바탕 비용 |
| **블룸** bloom | 광석·보석·결정 광맥과 희귀 군집 | 중간 변형과 모든 핵심 노드의 추가 비용 |
| **암반 코어** core | 코어 암반, 심층 핵 광맥, 보스 보장 | 핵심 노드와 캡스톤의 추가 비용 |

- GDD의 **유물 relic은 회수 미션 목표물**이므로 성장 재화로 소비하지 않는다.
- 일반 암반은 펄프를 확정 누적해 첫 노드 시점이 운에 좌우되지 않게 한다.
- 보스는 코어의 유일한 획득처가 아니라 운이 나쁜 런의 보장 지급처다.
- 성장 재화는 자동 습득해 전투 중 줍기 스트레스를 만들지 않는다.

### 4.2 노드 등급과 1차 비용

| 등급 | 표기 | 기본 비용 | 역할 |
|---|---|---:|---|
| 일반 | C | 펄프 8~14 | 첫 방향, 조작감 보정, 조건부 소효과 |
| 정제 | U | 펄프 18~26 + 블룸 1 | 직업 액션 형태를 바꾸는 중간 노드 |
| 핵심 | R | 펄프 34~46 + 블룸 3 + 코어 1 | 빌드 문장을 결정하는 중요 노드 |
| 캡스톤 | K | 펄프 60 + 블룸 6 + 코어 2 | 같은 분야 8개 구매 후 열리는 최종 변형 |

상위 노드는 하위 재화를 대체하지 않고 모두 함께 소비한다. 깊은 런에서도 일반 암반 채굴이 계속 유효하다.

### 4.3 목표 속도와 운 보정

| 항목 | 1차 목표 |
|---|---|
| 첫 일반 노드 | 시작 후 45~75초 |
| 일반 노드 간격 | 60~120초 |
| 첫 블룸 / 정제 노드 | 2~4분 / 4~6분 |
| 첫 코어 / 핵심 노드 | 7~10분 / 10~14분 |
| 첫 캡스톤 | 20~26분 |
| 30분 총 구매 | 16~20개 |

- 펄프는 확률 드롭 대신 파괴량 누적으로 지급한다.
- 블룸을 4분간 못 찾으면 다음 미탐색 구역의 광맥 가중치를 높인다.
- 코어를 10분간 못 얻으면 다음 심층 광맥 또는 보스가 반드시 지급한다.
- 재화 획득 노드의 할인과 추가 획득은 중첩하지 않는다.
- 런 종료 잔여 재화는 영구 공격력으로 바꾸지 않고 점수·발견 기록에만 반영한다.
- 펄프→블룸 저효율 교환은 테스트 후보지만 블룸→코어 변환은 금지한다.

## 5. 트리 구조와 점진 공개

### 5.1 한 캐릭터의 구성

| 영역 | 수 | 목적 |
|---|---:|---|
| 중앙 코어 | 1 | 무료 시작점, 현재 직업 표시 |
| 공용 기초 | 18 | 생존·조작·채굴 편의 |
| 직업 전용 | 36 | 직업별 3개 전문 분야, 분야당 12개 |
| 합계 | **55개 지점 / 구매 노드 54개** | 중앙 코어는 구매하지 않음 |

시작 시 보이는 것은 중앙 코어, 공용 생존·조작·채굴 루트, 현재 직업 루트까지 정확히 다섯 지점이다. 미발견 노드는 빈 슬롯이나 물음표로도 표시하지 않는다.

### 5.2 분야별 12노드 연결 문법

    03 ── 06 ── 09
   ╱  ╲  ╱  ╲    ╲
ROOT─01─04─07─10──12
   ╲  ╱  ╲  ╱    ╱
    02 ── 05 ── 08 ── 11

- 01·02는 첫 방향, 03~05는 보완·우회, 06~08은 행동 변형, 09~11은 핵심, 12는 캡스톤이다.
- 캡스톤은 같은 분야 8개 이상 구매와 코어 비용을 모두 요구한다.
- 교차 연결은 막다른 길과 원치 않는 고가 노드 강매를 줄인다.

### 5.3 공개 상태와 규칙

| 상태 | 표시 | 상호작용 |
|---|---|---|
| 미발견 | 화면에 없음 | 불가 |
| 감지 | 암석 속 맥동만 표시, 이름 비공개 | 불가 |
| 공개·잠금 | 아이콘·이름과 부족 조건 표시 | 확인 |
| 구매 가능 | 직업색 테두리와 비용 표시 | 구매 |
| 활성 | 중심광과 흐르는 연결선 | 효과 적용 |
| 단절 예정 | 환불 시 끊길 경로 경고 | 환불 불가 |

- 구매 시 연결된 1칸 이웃만 공개한다.
- 핵심·캡스톤은 2칸 안에서 이름 없는 **광맥 맥동**만 보여 방향을 힌트한다.
- 이름·효과·정확한 비용은 인접 노드 구매 후 공개한다.
- 공개 애니메이션은 0.45초 이하이며 입력을 막지 않는다.
- 발견 노드는 런 종료 후 직업별 도감에 기록한다.
- 다음 런의 인게임 트리는 다시 안개로 시작하고 도감에서 과거 발견 내용을 검토한다.
- 트리 연결과 위치는 직업별 고정이다. v0.2에서는 절차 생성하지 않는다.

### 5.4 막다른 길 방지

- 일반·정제 노드의 80% 이상은 연결을 두 개 이상 가진다.
- 핵심 노드는 최소 두 경로에서 접근 가능해야 한다.
- 캡스톤 마지막 두 길은 서로 다른 플레이 방식이어야 한다.
- 원치 않는 핵심을 반드시 사야 다른 핵심으로 가는 구조를 금지한다.
- 3회 연속 되돌아간 경로는 연결선 추가 또는 비용 조정 후보로 기록한다.

## 6. 실시간 특성 창 UX

### 6.1 입력과 시간

- **왼쪽 Tab:** 특성 창 열기·닫기
- 휠: 확대·축소
- 가운데 버튼 또는 빈 공간 드래그: 화면 이동
- 노드 클릭 후 재클릭 또는 구매 버튼: 구매 확정
- Esc: 닫기
- 브라우저 게임 포커스에서만 Tab 기본 포커스 이동을 막는다.
- 설정 명칭은 **특성 회로 열기**이며 키 재지정을 허용한다.

**솔로 권장안:** 창이 열려도 세계가 20% 속도로 진행된다. 무적은 없고 피해를 받으면 창을 닫은 뒤 0.35초 동안 이동 입력을 보존한다.

**코옵 권장안:** 세계는 100% 진행하며 최근 공개 6개를 먼저 보여주는 빠른 구매 패널을 제공한다.

20% 감속은 검증 중이다. 0%·20%·완전 정지를 비교하되 목표는 어디서든 즉시 성장시키는 접근성이다.

### 6.2 화면과 피드백

- 왼쪽 72%: 안개형 그래프
- 오른쪽 28%: 효과 비교, 비용, 선행 조건
- 상단: 세 재화와 다음 구매 부족량
- 하단: 빌드 요약, 직전 구매 되돌리기, 도감
- 배경은 현재 게임을 어둡게만 하며 완전히 가리지 않는다.
- 등급은 색뿐 아니라 모양으로도 구분한다.
- 구매 시 재화 흡수 → 연결선 점등 → 인접 노드 출현 → 새 효과 한 문장 순으로 피드백한다.
- 캡스톤은 전용 사운드·화면 테두리·장비 VFX를 함께 갱신한다.

## 7. 구매·환불·저장

- 구매는 어디서든 가능하고 즉시 현재 런에 적용된다.
- 캡스톤은 분야 8개 이상 구매가 필요하다. 두 번째 캡스톤은 코어 비용 +1이다.
- 구매 후 10초 안에는 직전 구매 1개를 전액 환불한다.
- 그 효과로 적·벽에 영향을 줬거나 파생 노드를 구매하면 즉시 되돌리기가 닫힌다.
- 심층 이동 전에는 분야별 또는 전체 초기화를 무료로 제공하고 재화를 100% 반환한다.
- 전투 중 전체 초기화와 연결이 끊기는 부분 환불은 불가하다.
- 구매 노드와 재화는 런 종료 시 초기화한다.
- 직업별 발견 도감, 튜토리얼 확인, 즐겨찾기 빌드 문장만 계정에 남긴다.
- 영구 메타는 외형·도감 편의만 제공하고 필수 영구 공격력을 주지 않는다.

## 15. 밸런스 안전장치

### 15.1 획득과 수치

- 30분 기준 공용 4~6개, 전용 12~14개가 기본 목표다.
- 공용 구매가 전체의 40%를 넘으면 공용 효율 또는 전용 진입 비용을 조정한다.
- 첫 캡스톤은 20~26분, 두 번째는 40분 이후에만 현실적인 비용으로 둔다.
- 순수 피해·체력·속도만 올리는 노드는 전체의 15% 이하로 제한한다.
- 수치 증가에도 발동 조건, 피드백, 사용법 변화 중 하나를 붙인다.

### 15.2 연쇄와 경제

- 파괴·폭발·균열 전파는 이벤트당 세대 수와 대상 수를 제한한다.
- 전파 효과는 같은 프레임에 자신을 다시 호출하지 않는다.
- 설치물 공유 버프는 설치물 수에 따라 무한 곱연산하지 않고 상한을 둔다.
- 재화 획득 노드는 직접 전투력보다 낮은 효율을 가진다.
- 블룸·코어 보정은 운이 나쁜 런만 끌어올리고 평균 수입을 계속 증폭하지 않는다.
- 팀 시너지는 혼자서도 기본 기능이 완성된 뒤 추가 이득을 주는 방식으로 만든다.

## 16. 코옵 규칙

- 노드 트리와 구매 재화는 플레이어별이다.
- 펄프는 실제 채굴자에게 주되 일정 거리 안 팀원에게 30% 공동 작업 보너스를 준다.
- 블룸·코어 광맥 완전 채굴 시 가까운 팀원 모두에게 개인 몫을 지급해 마지막 타격 경쟁을 막는다.
- 보스 코어는 생존 중인 모든 플레이어에게 동일 지급한다.
- 스카우트 표식, 거너 방벽, 엔지니어 전력망, 드릴러 균열은 팀에 보이지만 성장 수치는 소유자 트리만 따른다.
- 호스트 트리 상태가 다른 플레이어의 구매 가능 여부를 바꾸지 않는다.
- 재접속 시 현재 런의 구매 노드·재화·공개 상태를 복원한다.

## 17. 접근성과 정보 설계

- 등급은 색과 모양을 함께 쓴다: 원형 C, 육각 U, 마름모 R, 왕관형 K.
- 연결선은 활성·구매 가능·잠금을 선 굵기와 움직임으로도 구분한다.
- 안개 강도, 감속, 공개 애니메이션, 화면 흔들림을 옵션에서 낮출 수 있다.
- 툴팁은 **무엇이 바뀌는가 → 언제 발동하는가 → 정확한 수치** 순서로 쓴다.
- 현재 효과와 구매 후 효과를 나란히 비교한다.
- 캡스톤까지 남은 조건을 노드 수와 재화로 분리해 표시한다.
- 키보드만으로 인접 노드 이동과 구매가 가능해야 한다.
- 도감에 검색, 직업, 분야, 등급, 발견 여부 필터를 제공한다.

## 20. 검증 계획

### 20.1 기능

- 시작 시 중앙 포함 정확히 5개 지점만 보인다.
- 구매 시 1칸 이웃만 공개되고 미발견 노드의 이름·아이콘이 UI 구조에도 노출되지 않는다.
- 재화 부족, 선행 단절, 분야 투자 부족 시 구매가 막힌다.
- 직전 구매 되돌리기는 사용 전 10초 안에만 전액 반환한다.
- 층간 초기화 후 모든 파생 상태와 설치물이 기본 규칙으로 재계산된다.
- Tab 기본 동작은 게임 포커스에서만 차단된다.
- 피해 자동 닫힘 뒤 이동 입력이 씹히지 않는다.
- 코옵에서 한 사람의 특성 창이 다른 플레이어 시간을 늦추지 않는다.

### 20.2 재미와 경제

- 신규 플레이어 첫 구매가 20초 안에 끝난다.
- 10분 시점에 빌드를 한 문장으로 설명할 수 있다.
- 캡스톤 구매 후 30초 안에 조작 또는 화면 변화가 관찰된다.
- 공용만 사는 런이 전체의 15%를 넘지 않는다.
- 직업 내 한 분야 선택률이 장기간 60%를 넘지 않는다.
- 첫 노드 중앙값 60초, 첫 정제 5분, 첫 핵심 12분, 첫 캡스톤 23분을 목표로 한다.
- 10분까지 블룸 0 또는 코어 0인 런은 각각 5% 미만이어야 한다.
- 30분 생존자의 구매 중앙값은 16~20개다.
- 상위 10% 채굴 빌드도 30분에 전체 노드 50%를 넘지 않는다.

### 20.3 점진 공개

- 중요 노드 맥동을 보고 실제 경로를 잘못 이해하는 비율을 측정한다.
- 공개 후 되돌아가는 막다른 길이 런당 평균 1회보다 많으면 연결을 추가한다.
- 안개 때문에 계획이 어렵다는 의견과 도감 때문에 발견 재미가 줄었다는 의견을 분리한다.
- 첫 런·세 번째·열 번째 런의 트리 체류 시간을 비교한다.
