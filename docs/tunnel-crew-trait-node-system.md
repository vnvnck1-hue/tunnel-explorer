# 땅굴 크루 특성 노드 시스템

> 상태: **v0.1 기능 설계 확정 · 수치 검증 전**  
> 최종 갱신: 2026-08-27  
> 1차 적용 범위: **무한 모드의 런 전용 성장**  
> 기준 구현: `tunnel-crew-infinite-mode-v7.1.4.html`

이 문서는 땅굴 크루의 특성 노드 시스템에 관한 **누적형 단일 기준 문서**다. 이후 직업 트리, 공통 규칙, 수치 조정, 플레이테스트 결과와 변경 이유를 이 파일에 계속 추가한다.

## 문서 운영 규칙

- 효과의 구조와 플레이 방식이 합의되면 `기능 확정`으로 표시한다.
- 피해량, 지속시간, 확률 등은 실제 플레이테스트 전까지 `1차 수치`로 취급한다.
- 기존 결정을 바꿀 때는 내용을 조용히 덮어쓰지 않고 아래 변경 기록에 이유를 남긴다.
- 구현과 문서가 다르면 문서를 먼저 갱신한 뒤 구현을 맞춘다.
- 상태 표기는 `확정`, `검증 중`, `보류`, `폐기` 네 가지를 사용한다.

## 변경 기록

### 2026-08-27 · v0.1

- 최근 스팀 게임의 특성 트리 흐름을 비교했다.
- 땅굴 크루에는 거대 패시브 웹이 아니라 **직업별 소형 변형 트리**를 사용하기로 했다.
- 레벨업 카드, 직업 특성 트리, 메타 성장의 역할을 분리했다.
- 드릴러 트리를 `굴진 과급`, `균열 공학`, `돌파 파기` 3분기 15노드로 확정했다.

### 1.2 반복해서 나타나는 설계 흐름

1. 거대한 트리 하나보다 **직업·무기·활성 스킬 단위의 작은 트리**를 사용한다.
2. `피해량 +5%` 같은 연결용 노드를 줄이고 변형 노드의 비중을 높인다.
3. 끝 노드는 플레이 방식과 화면을 동시에 바꾸는 캡스톤으로 만든다.
4. 한 런에서 모든 노드를 찍지 못하게 해 빌드의 문장이 남게 한다.
5. 초기화 비용을 낮춰 실패한 빌드보다 실험 자체를 장려한다.
6. 범용 필수 기능은 한 분기의 세금 노드로 사용하지 않는다.

### 1.3 피해야 할 패턴

- 원하는 노드에 가기 위해 의미 없는 수치 노드를 여러 개 사는 구조
- 툴팁 수치는 커지지만 조작과 화면은 그대로인 캡스톤
- 모든 직업이 후반에 같은 공용 트리를 완성해 역할 개성이 사라지는 구조
- 랜덤 카드, 전설 보상, 고정 트리가 같은 종류의 효과를 중복 제공하는 구조
- 초기화가 비싸 첫 선택 실수가 런 전체를 망치는 구조

## 2. 땅굴 크루의 현재 상태

현재 무한 모드에는 이미 세 종류의 런 성장이 공존한다.

1. 레벨업 시 직업 전용 특성 3장 중 1장을 고르는 랜덤 성장 `INF_TRAITS`
2. 보스 처치 뒤 전설 카드 3장 중 1장을 고르는 `INF_LEGENDS`
3. 코어로 `굴진·관통·동력·장악`을 구매하는 공용 직선 트리 `INF_BRANCHES`

현재 공용 트리는 4분기 × 3노드지만 모든 분기가 직선이라 구매 순서 이상의 선택이 적다. 또한 공용 화력과 성장 가속이 강해질수록 드릴러, 거너, 스카우트, 엔지니어가 비슷한 후반 빌드로 수렴한다.

기존 GDD는 10~20분 라이트 미션과 얇은 메타 진행을 목표로 하며 스킬트리를 본편 필수 요소에서 제외했다. 따라서 이번 특성 트리는 우선 **무한 모드 안에서만 검증**한다. 일반 미션 모드 도입은 별도 결정으로 남긴다.

## 3. 시스템 방향 확정

### 3.1 성장 층의 역할

| 성장 층 | 담당하는 것 | 담당하지 않는 것 |
|---|---|---|
| 레벨업 카드 | 연사력, 반경, 지속시간, 재장전처럼 즉시 체감되는 반복 수치 성장 | 스킬의 정체성을 완전히 바꾸는 효과 |
| 직업 특성 트리 | 원격 기폭, 영구 균열, 자율 터렛처럼 플레이 방식을 바꾸는 확정 성장 | 작은 수치를 여러 번 중첩하는 성장 |
| 캡스톤 | 조작, 리스크, 지형 반응과 VFX까지 바꾸는 빌드 완성 효과 | 단순 종합 수치 보너스 |
| 메타 진행 | 새 선택지, 외형, 시작 프리셋 해금 | 필수 영구 공격력 누적 |

보스 전설 카드가 제공하던 빌드 결정 효과는 장기적으로 각 직업 트리의 캡스톤이나 선택 노드로 이동한다. 별도 전설 선택과 특성 트리를 한 화면에서 동시에 처리하는 현재 구조는 정리 대상이다.

### 3.2 트리 형태

직업 하나는 3분기로 구성하며 분기마다 화면에 5개 노드가 보인다.

```text
T1 기반 노드
     │
     ├── T2-A 변형 ──┐
     │                ├── T3 연계 강화 ── T4 캡스톤
     └── T2-B 변형 ──┘
```

- 한 분기의 표시 노드: 5개
- 실제로 구매하는 노드: 기반 1 + 양자택일 1 + 연계 1 + 캡스톤 1 = 4개
- 직업 전체 표시 노드: 15개
- T2-A와 T2-B는 상호 배타적이다.
- T3는 어느 T2를 골라도 기능해야 한다.
- T4는 해당 분기에 3포인트를 투자해야 열린다.
- 모든 노드의 기본 비용은 특성 포인트 1점이다.
- 휴식 화면에서는 다음 심층으로 내려가기 전 무료 초기화를 허용한다.

### 3.3 특성 포인트 경제

`확정`: 보스 처치 때 특성 포인트 1점을 지급한다. 4개 보스를 한 분기에 집중 투자하면 첫 캡스톤에 도달한다.

`보류`: 현재 희귀 광맥과 보스가 지급하는 `암반 코어`를 특성 포인트로 전환할지, 레벨업 카드 재굴림 등 별도 자원으로 남길지는 드릴러 수직 슬라이스의 성장 속도 테스트 후 결정한다. v0.1에서는 특성 포인트와 기존 코어를 분리해 측정한다.

### 3.4 공통 노드 작성 규칙

- 한 노드의 플레이어용 설명은 두 문장을 넘지 않는다.
- 순수 수치 노드는 각 분기의 T1에만 허용하며 체감 보정 기능을 함께 붙인다.
- T2는 서로 우열이 아니라 대상, 범위 또는 리스크가 달라야 한다.
- T3는 앞에서 고른 변형을 강화하거나 다른 분기와 연결한다.
- 캡스톤은 전용 VFX와 상태 표시를 가진다.
- 내부 재귀로 무한 연쇄가 생기지 않도록 전파 효과는 한 이벤트당 횟수와 대상을 제한한다.

## 4. 드릴러 특성 트리 v0.1

### 4.1 직업 판타지

> 드릴러는 단순히 벽 피해가 높은 직업이 아니라, **막힌 지형에 작업을 축적하고 결국 길 자체를 바꾸는 직업**이다.

드릴러의 세 빌드 문장은 다음처럼 달라야 한다.

- 굴진 과급: “열을 감수하고 멈추지 않고 전진한다.”
- 균열 공학: “여러 기반암에 균열을 심어 연쇄 붕괴시킨다.”
- 돌파 파기: “Q 한 번으로 긴 통로와 전투 공간을 만든다.”

### 4.2 전체 연결도

```text
[굴진 과급]
토크 증폭 모터
  ├─ 관성 플라이휠 ─┐
  └─ 편향식 커터 헤드 ┴─ 열회수 터빈 ─ 무정지 과급

[균열 공학]
균열 고착 수지
  ├─ 단층 추적 비트 ─┐
  └─ 분기 균열침 ─────┴─ 응력 전달 계전기 ─ 영구 단층 각인

[돌파 파기]
과압 실린더
  ├─ 종방향 천공 노즐 ─┐
  └─ 지진 확산판 ───────┴─ 압력 재순환 밸브 ─ 맨틀 천공 키
```

## 5. 분기 A — 굴진 과급

일반 암반 굴착, 드릴 예열과 과열을 이용해 전진 속도를 극대화하는 분기다.

| 단계 | ID | 노드 | 플레이어용 효과 | 설계·구현 메모 |
|---|---|---|---|---|
| T1 | `d_pressure_torque` | **토크 증폭 모터** | 드릴 피해와 기반암 균열 압력 +15%. 드릴 열 발생량 -10%. | 기존 `d_motor`를 트리 기반 노드로 이동한다. `drillMul`과 열 증가 계수를 함께 조정한다. |
| T2-A | `d_pressure_flywheel` | **관성 플라이휠** | 같은 타일을 0.7초 연속 굴착하면 `정렬` 상태가 되어 해당 타일에 드릴 피해와 균열 압력 +35%. 조준을 바꾸거나 드릴을 놓으면 해제된다. | 단일 기반암과 보스 장갑을 빠르게 뚫는 정밀 선택지다. 타깃 인덱스와 유지시간을 추적한다. |
| T2-B | `d_pressure_deflector` | **편향식 커터 헤드** | 일반 암반을 파괴하면 진행 방향 좌우의 인접 암반 최대 2개에 그 타격의 65% 피해를 준다. | 넓은 통로를 만드는 범위 선택지다. 연쇄 피해가 다시 발동하지 않도록 1회 잠금을 사용한다. |
| T3 | `d_pressure_recovery` | **열회수 터빈** | 일반 암반 파괴 시 드릴 열 12% 감소. 기반암 또는 코어 암반 돌파 시 30% 감소하고 과열 잠금이 0.35초 단축된다. | T2-A는 큰 목표 처치 보상, T2-B는 다수 파괴 보상으로 함께 작동한다. |
| T4 | `d_pressure_redline` | **무정지 과급** | 열이 90% 이상이면 드릴이 과열로 정지하지 않고 드릴 피해와 균열 압력 +45%. 최대 열로 굴착하는 동안 초당 최대 체력의 2%를 잃는다. | 기능 확정, 피해 수치는 검증 중. 백열 드릴, 붉은 열 게이지, 경고음을 전용 피드백으로 사용한다. 체력은 1 아래로 내려가지 않게 할지 테스트에서 결정한다. |

### 예상 플레이

- `관성 플라이휠`은 기반암, 코어 암반, 보스 장갑에 집중하는 안전한 정밀 굴진이다.
- `편향식 커터 헤드`는 일반 벽을 넓게 지워 이동 공간을 만드는 속도 굴진이다.
- `무정지 과급`은 냉각 대기 대신 체력을 자원으로 사용하는 명확한 리스크형 캡스톤이다.

## 6. 분기 B — 균열 공학

기반암에 남긴 작업량을 보존하고 다른 기반암으로 전달해 지형을 계획적으로 무너뜨리는 분기다.

| 단계 | ID | 노드 | 플레이어용 효과 | 설계·구현 메모 |
|---|---|---|---|---|
| T1 | `d_fracture_resin` | **균열 고착 수지** | 균열 감소가 시작되는 유예시간 +1.25초. 균열 소실 속도 -25%. | 기존 `d_resin`을 이동한다. 여러 목표를 오가도 작업이 헛되지 않게 하는 기반 노드다. |
| T2-A | `d_fracture_tracker` | **단층 추적 비트** | 같은 기반암을 0.65초 연속 굴착하면 해당 기반암의 균열 압력 +40%. | 기존 `d_fault`의 단순 수치를 타깃 집중형 행동으로 바꾼다. LMB 정밀 작업 선택지다. |
| T2-B | `d_fracture_branch_pin` | **분기 균열침** | 돌파 파기 Q가 처음 맞힌 기반암 주변의 기반암 최대 2개에 25% 균열을 남긴다. 코어 암반에는 15%만 적용된다. | Q로 여러 작업 지점을 미리 만드는 분산 선택지다. 한 시전당 최대 2개로 제한한다. |
| T3 | `d_fracture_relay` | **응력 전달 계전기** | 기반암을 돌파하면 3타일 안에서 균열도가 가장 높은 다른 기반암 1개에 돌파한 균열의 40%를 전달한다. | 기존 `d_recirc`를 행동형 효과로 재해석한다. 대상이 없으면 발동하지 않는다. |
| T4 | `d_fracture_eternal` | **영구 단층 각인** | 생성한 균열이 더는 소실되지 않는다. 기반암 돌파 시 4타일 안의 기반암 최대 3개에 30% 균열을 새기고 주변 일반 암반에 파쇄 충격을 준다. | 기존 `d_eternal`과 `d_seismic` 일부를 통합한 캡스톤이다. 금색 균열망이 퍼지는 전용 VFX가 필요하다. 전파로 생긴 균열은 같은 프레임에 다시 전파되지 않는다. |

### 예상 플레이

- `단층 추적 비트`는 하나씩 확실하게 뚫은 뒤 응력을 다음 목표로 넘긴다.
- `분기 균열침`은 Q로 여러 기반암에 씨앗을 심은 뒤 순서를 정해 연쇄 붕괴시킨다.
- `영구 단층 각인` 이후 플레이어가 지나간 공간 전체가 다음 붕괴를 준비하는 작업망으로 남는다.

## 7. 분기 C — 돌파 파기

Q 기술의 거리, 범위와 재사용 주기를 바꾸어 순간적으로 통로와 전투 공간을 만드는 분기다.

| 단계 | ID | 노드 | 플레이어용 효과 | 설계·구현 메모 |
|---|---|---|---|---|
| T1 | `d_breach_cylinder` | **과압 실린더** | 돌파 파기 Q의 피해와 균열 압력 +25%. 재사용 대기시간 -15%. | 기존 `d_pressure`를 이동한다. 분기의 체감 진입점이다. |
| T2-A | `d_breach_longitudinal` | **종방향 천공 노즐** | 돌파 파기의 직선 사거리가 3타일에서 5타일로 증가하고 중심선 균열 압력 +20%. | 멀리 있는 기반암과 보스 장갑을 노리는 직선 선택지다. 폭은 늘리지 않는다. |
| T2-B | `d_breach_diffuser` | **지진 확산판** | 돌파 파기가 중심선 좌우 1타일에도 55% 피해와 균열 압력을 가한다. 중심선 사거리는 1타일 감소한다. | 기존 `d_seismic`을 광역 Q 선택지로 이동한다. 넓은 방을 만드는 대신 도달 거리를 포기한다. |
| T3 | `d_breach_recirculation` | **압력 재순환 밸브** | 돌파 파기로 일반 암반을 파괴할 때마다 Q 재사용 대기시간 0.25초 감소, 한 번의 시전에서 최대 1.5초. 기반암 또는 코어 암반 돌파 시 추가로 2초 감소한다. | 좁은 직선과 넓은 파쇄가 모두 파괴 수에 따라 보상받는다. 현재 쿨다운에서 즉시 차감한다. |
| T4 | `d_breach_mantle_key` | **맨틀 천공 키** | 돌파 파기가 `맨틀 돌파`로 변한다. 현재 사거리 +2타일, 중심선의 일반 암반을 즉시 파괴하고 처음 맞힌 기반암에 60% 고정 균열을 추가하며 코어 암반의 필요 압력을 35% 낮춘다. | 기존 `d_mantle`을 행동 변형 캡스톤으로 강화한다. 보라색·금색 관통 파동과 화면 흔들림을 사용한다. 한 시전에서 고정 균열은 한 대상에만 적용한다. |

### 예상 플레이

- `종방향 천공 노즐`은 좁고 긴 탈출로와 원거리 기반암 공략에 특화된다.
- `지진 확산판`은 적에게 둘러싸인 공간을 넓히고 보스 장갑벽을 여러 장 동시에 깎는다.
- `맨틀 천공 키`는 Q를 단순 쿨다운 공격에서 지형을 관통하는 대표 기술로 바꾼다.

## 8. 기존 드릴러 특성 이관표

| 기존 특성 | 새 위치 | 처리 |
|---|---|---|
| 토크 증폭 모터 `d_motor` | 굴진 과급 T1 | 수치 조정 후 이동 |
| 균열 고착 수지 `d_resin` | 균열 공학 T1 | 이동 |
| 단층 추적 비트 `d_fault` | 균열 공학 T2-A | 집중 유지 행동 추가 |
| 과압 실린더 `d_pressure` | 돌파 파기 T1 | 이동 |
| 지진 공진축 `d_seismic` | 돌파 파기 T2-B 및 균열 캡스톤 | 범위 Q와 연쇄 붕괴로 역할 분리 |
| 열회수 균열기 `d_recirc` | 균열 공학 T3 | 수치형에서 응력 전달형으로 변경 |
| 맨틀 천공 키 `d_mantle` | 돌파 파기 T4 | Q 변형 캡스톤으로 강화 |
| 영구 단층 각인 `d_eternal` | 균열 공학 T4 | 영구 균열과 제한 전파를 결합 |

이관이 끝나면 위 8개 효과는 레벨업 랜덤 카드 풀에서 제거한다. 드릴러 레벨업 카드 풀은 별도로 작은 반복 강화 6~8개를 새로 설계해야 한다.

## 9. 분기 간 시너지와 경계

| 조합 | 만들어지는 플레이 |
|---|---|
| 관성 플라이휠 + 단층 추적 비트 | 하나의 기반암과 보스 장갑을 빠르게 제거하는 정밀 굴진 |
| 편향식 커터 헤드 + 지진 확산판 | 넓은 통로와 전투 공간을 빠르게 만드는 광역 굴진 |
| 분기 균열침 + 압력 재순환 밸브 | Q로 균열 씨앗을 심고 파괴 수만큼 다음 Q를 앞당기는 순환 빌드 |
| 응력 전달 계전기 + 맨틀 천공 키 | Q로 첫 기반암을 크게 열고 남은 응력을 다음 기반암에 넘기는 연쇄 빌드 |

경계 원칙:

- 굴진 과급은 `일반 암반과 열 관리`가 중심이다.
- 균열 공학은 `시간을 두고 남는 기반암 작업량`이 중심이다.
- 돌파 파기는 `Q 한 번의 공간 변화`가 중심이다.
- 어느 분기도 리벳 권총의 직접 화력을 주력으로 강화하지 않는다. 드릴러의 전투 기여는 지형 개방, 보스 장갑 해체와 드릴 근접 위험을 통해 만든다.

## 10. 구현 데이터 초안

```js
{
  id: 'd_fracture_branch_pin',
  role: 'driller',
  branch: 'fracture',
  tier: 2,
  cost: 1,
  requires: ['d_fracture_resin'],
  excludes: ['d_fracture_tracker'],
  effectId: 'driller_branch_crack_pin',
  status: 'functional_locked'
}
```

노드 정의와 실제 효과 함수는 분리한다. 트리 UI는 `requires`와 `excludes`만 읽고, 게임플레이 코드는 `effectId`에 대응하는 런 상태를 적용한다. 이렇게 해야 초기화, 저장, 툴팁 비교와 밸런스 패치를 안전하게 처리할 수 있다.

## 11. 드릴러 수직 슬라이스 검증 기준

### 기능 검증

- T2-A를 구매하면 같은 분기의 T2-B를 구매할 수 없다.
- 무료 초기화 후 모든 파생 런 상태가 기본값으로 정확히 돌아간다.
- 전파 피해와 균열이 자기 자신을 재귀 호출하지 않는다.
- 심층 이동과 맵 재생성 뒤 영구 균열 데이터는 새 층에 남지 않는다.
- 캡스톤의 상태가 HUD, 캐릭터·드릴 VFX, 사운드 중 최소 두 곳에 표시된다.

### 재미 검증

- 심층 3 이전에 플레이어가 자신의 빌드를 한 문장으로 설명할 수 있다.
- 세 분기 중 어느 하나의 선택률도 70%를 지속적으로 넘지 않는다.
- 각 T2 양자택일이 최소 30% 이상의 선택률을 가진다.
- 첫 선택은 20초, 같은 트리의 반복 선택은 8초 안에 끝난다.
- 캡스톤 구매 직후 30초 안에 플레이 방식의 변화를 체감한다.

### 1차 테스트 조합

1. 굴진 과급 전용 4포인트
2. 균열 공학 전용 4포인트
3. 돌파 파기 전용 4포인트
4. 굴진 2 + 균열 2
5. 균열 2 + 돌파 2
6. 굴진 2 + 돌파 2

각 조합에서 일반 벽 100개 파괴 시간, 기반암 5개 돌파 시간, 받은 피해, Q 사용 횟수와 보스 장갑 해체 시간을 기록한다.
