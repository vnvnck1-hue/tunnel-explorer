# 땅굴 크루 — 팀 핑 시스템 기획서 v0.1

> 상태: 1차 기획안 · 구현 전 검증 필요  
> 작성: 2026-09-02  
> 적용 대상: 2~4인 LAN/온라인 코옵, 로컬 AI 크루 동행 플레이  
> 목표: 음성 채팅 없이도 1초 안에 위치·위험·의도를 팀에 전달한다.

---

## 1. 기획 의도

땅굴 크루는 어두운 타일 지형에서 길을 만들고, 광맥을 발견하고, 적을 막고, 탈출 지점에 집결하는 협동 게임이다. 플레이어가 보고 있는 대상과 다음 행동을 빠르게 공유하지 못하면 역할 분담이 흐려지고, 각자가 따로 움직이게 된다.

핑 시스템은 리그 오브 레전드의 **누르기 → 방향 선택 → 떼어서 확정하는 방사형 핑 휠**을 기본 조작으로 삼는다. 다만 전선·라인 중심의 신호를 그대로 복사하지 않고, 땅굴 크루의 핵심 상황인 **채굴, 발견, 전투, 이동, 방어, 집결**에 맞게 의미를 바꾼다.

### 1.1 목표

- 이동이나 조준을 크게 멈추지 않고 신호를 보낼 수 있다.
- 아이콘, 색, 소리 중 하나만 인지해도 뜻을 짐작할 수 있다.
- 월드 안의 정확한 위치와 플레이어의 의도를 함께 전달한다.
- 사람 크루뿐 아니라 AI 크루에게도 간단한 명령으로 작동한다.
- 반복 신호, 악의적 도배, 화면 가림을 시스템 차원에서 억제한다.

### 1.2 하지 않는 것

- 자유 문장 채팅을 대체하는 복잡한 명령 체계
- AI에게 세밀한 이동 경로와 전술을 지정하는 RTS식 지휘
- 핑 사용 자체에 경험치나 재화 보상을 주는 설계
- 역할별로 서로 다른 휠을 외워야 하는 구조
- 시야 밖의 미발견 정보를 핑으로 알아내는 정찰 치트

## 2. 핵심 조작

현재 조작의 `WASD` 이동, 마우스 조준, 좌·우클릭 장비 사용, 마우스 휠 무기 전환, `Space` 대시, `Q/E` 역할 기능, `Tab` 키 가이드와 충돌하지 않도록 `G`와 `V`를 사용한다.

| 입력 | 결과 |
|---|---|
| `G` 짧게 누르고 떼기 | 마우스 커서 위치에 **기본 핑** |
| `G` 누른 채 마우스 이동 | 8방향 **핑 휠** 표시 및 항목 선택 |
| `G` 떼기 | 선택한 핑을 커서의 월드 위치에 전송 |
| `G`를 누른 채 휠 중앙으로 복귀 후 떼기 | 취소 |
| `Esc` 또는 마우스 우클릭 | 핑 휠 취소 |
| `V` 짧게 누르기 | 커서 위치에 **위험 핑** 즉시 전송 |

### 2.1 입력 판정값

- `G`를 누른 뒤 **120ms 이내**에 떼고 포인터 이동이 **18px 미만**이면 기본 핑으로 판정한다.
- 포인터가 휠 중심에서 **24px 이상** 벗어나면 해당 방향의 항목을 선택한다.
- 휠 반지름은 96px, 시각적 데드존은 24px로 시작해 해상도 배율을 적용한다.
- 휠이 열린 동안에도 `WASD` 이동은 유지한다. 좌·우클릭 장비 사용은 새 입력을 받지 않으며, 이미 홀드 중인 장비 사용은 `G`를 누르는 순간 종료한다.
- 키를 잃은 `blur`, 창 전환, 포인터 캔슬 상황에서는 핑을 보내지 않고 취소한다.
- 기본 키는 설정에서 재지정할 수 있다.

### 2.2 컨트롤러 후속안

컨트롤러 최적화 단계에서는 `십자키 아래 홀드 + 오른쪽 스틱 방향 + 떼기`를 핑 휠로 사용한다. 십자키 아래 탭은 기본 핑, 십자키 오른쪽 탭은 위험 핑으로 둔다. 키보드·마우스 1차 구현에는 포함하지 않는다.

## 3. 핑 종류와 휠 배치

항상 같은 위치에 같은 의미를 배치해 근육 기억을 만든다. 위쪽은 전진, 아래쪽은 후퇴, 왼쪽은 도움, 오른쪽은 발견이라는 공간적 규칙을 사용한다.

| 방향 | 핑 | 색 | 전달 의미 | 대표 사용처 |
|---|---|---|---|---|
| 중앙/탭 | **여기** | 청색 | 위치를 가볍게 주목 | 갈림길, 낙하 지점, 일반 위치 공유 |
| ↑ | **가자** | 녹색 | 이 지점으로 이동·진행 | 다음 굴착 방향, 지층 입구, 보스 진입 |
| ↗ | **공격** | 적색 | 이 대상을 우선 공격 | 엘리트, 네스트, 보스 약점 |
| → | **발견** | 황금색 | 가치 있는 대상 발견 | 광맥, 유물, 보급품, 상호작용물 |
| ↘ | **채굴** | 주황색 | 이 지형을 파거나 길을 열자 | 단단한 암반, 막힌 길, 광맥 벽 |
| ↓ | **후퇴** | 적색 | 현재 위치에서 물러나자 | 몰려오는 적, 보스 광역기, 붕괴 위험 |
| ↙ | **방어** | 보라색 | 이 구역을 지키거나 설치물을 배치 | 채굴 거점, 탈출 포트, 좁은 길목 |
| ← | **도움** | 청록색 | 구조·지원이 필요 | 기절한 크루, 고립, 탄약·조명 부족 |
| ↖ | **위험** | 진홍색 | 적 또는 환경 위험 주의 | 적 무리, 함정, 낭떠러지, 보스 예고 |

### 3.1 명칭 원칙

- 화면에는 한글 2~3음절 동사형을 우선 사용한다.
- 아이콘만 보아도 `이동`, `공격`, `발견`, `채굴`, `후퇴`, `방어`, `도움`, `위험`이 구분되어야 한다.
- 역할명이나 전문 용어를 넣지 않는다. 어느 직업이 보내도 같은 뜻이어야 한다.
- 색만으로 구분하지 않는다. 모든 핑은 고유 실루엣, 짧은 텍스트, 서로 다른 음형을 함께 가진다.

## 4. 컨텍스트 핑

기본 핑 또는 휠 핑이 월드 대상 위에 놓이면, 서버/호스트가 알고 있는 대상 정보 범위에서 문구를 구체화한다. 핑의 종류는 유지하되 대상명이 덧붙는다.

| 대상 | 표시 예시 | 추가 동작 |
|---|---|---|
| 적·보스 | `공격 · 화염룡` / `위험 · 정예 굴벌레` | 대상이 살아 있는 동안 표식이 짧게 추적 |
| 광맥 | `발견 · 블룸 광맥` / `채굴 · 단단한 암반` | 해당 타일 또는 광맥 군집 중심에 고정 |
| 유물·보급품 | `발견 · 희귀 유물` | 습득되면 핑 조기 종료 |
| 기절한 크루 | `도움 · P3 구조` | 구조되거나 사망 상태가 바뀌면 종료 |
| 탈출 포트 | `가자 · 탈출 포트` / `방어 · 탈출 포트` | HUD 목표 정보와 연결 |
| 지층 입구·목표물 | `가자 · 심층 입구` | 화면 밖 방향 표시 유지 |
| 빈 바닥·벽 | 선택한 핑 이름 그대로 | 위치 핑으로 처리 |

### 4.1 정보 보안 규칙

- 핑은 송신자 또는 팀 공유 시야가 실제로 확인한 대상만 구체화한다.
- 미탐사 영역은 좌표 핑을 찍을 수 있으나 `알 수 없는 위치`로만 취급하고 내부 광물·적 정보를 노출하지 않는다.
- 움직이는 적 표식은 최대 2.5초만 추적하고 이후 마지막 확인 위치에 남는다.

## 5. 화면 표현

한 번의 핑은 **월드 마커**, **화면 가장자리 방향 표시**, **짧은 로그**의 세 층으로 전달한다.

### 5.1 월드 마커

- 핑 지점에 아이콘이 0.16초 동안 튀어나오고, 바닥 링이 0.45초 퍼진다.
- 기본 지속 시간은 4초, 위험·후퇴는 5초, 움직이는 적 표식은 최대 2.5초다.
- 마커 위에 `보낸 사람 · 핑 이름`을 1.2초 표시한 뒤 아이콘만 남긴다.
- 지형에 가려져도 아이콘은 읽히되, 반투명 처리해 실제 시야 오브젝트와 혼동하지 않게 한다.
- 같은 위치 1.5타일 안에 같은 종류 핑이 오면 새 마커를 쌓지 않고 강조 단계만 올린다.

### 5.2 화면 밖 표시

- 핑이 카메라 밖에 있으면 화면 안전 영역 가장자리에 화살표와 거리를 표시한다.
- 거리는 타일 단위로 반올림해 `12칸`처럼 표시한다.
- 위험·도움·후퇴는 거리와 관계없이 표시하고, 나머지는 30타일 이내에서만 표시한다.
- 동시에 표시하는 화면 밖 핑은 중요도순 최대 3개다: `도움 > 위험 > 후퇴 > 공격 > 방어 > 가자 > 채굴 > 발견 > 여기`.

### 5.3 핑 로그

- 화면 좌측 팀 상태 영역 근처에 `P2: 블룸 광맥 발견`처럼 한 줄을 3초간 표시한다.
- 최근 3개까지만 쌓고 오래된 항목부터 사라진다.
- 같은 사용자의 같은 핑이 2초 안에 반복되면 로그를 추가하지 않고 `×2`, `×3`으로 합친다.

### 5.4 사운드

- 모든 핑은 0.25~0.55초의 짧은 UI 신호음을 사용한다.
- 위험·후퇴는 낮고 강한 2연음, 도움은 상승 2연음, 발견은 밝은 단음처럼 의미별 음형을 구분한다.
- 거리에 따라 완전히 작아지지 않는 2D UI 음을 기본으로 하되, 좌우 방향감만 약하게 준다.
- 핑 음량은 효과음 설정을 따르며 별도 `팀 핑 음량` 슬라이더와 `핑 음소거`를 제공한다.

## 6. 팀 상호작용

### 6.1 사람 크루

- 핑은 파티 전체에 전송되며 보낸 사람의 닉네임·좌석 색을 함께 표시한다.
- 같은 대상에 다른 크루가 기본 핑을 찍으면 **동의**로 처리한다. 마커 외곽에 동의 수를 표시하고 지속 시간을 최대 2초 연장한다.
- 동의는 새로운 핑 1회로 계산하지 않아 도배 제한을 덜 소모한다.
- 핑을 직접 취소하는 기능은 송신자에게만 제공한다. 해당 마커 위에 커서를 두고 `G` 탭 시 취소한다.

### 6.2 AI 크루

AI는 핑을 절대 명령이 아니라 **짧은 우선순위 가중치**로 해석한다. 위험 회피, 기절자 구조, 생존 행동 같은 기존 최상위 판단은 핑보다 우선한다.

| 핑 | AI 반응 |
|---|---|
| 가자 | 안전 경로가 있으면 해당 위치로 집결, 8초 후 해제 |
| 공격 | 전투 가능한 AI가 대상 우선순위를 올림, 대상 소실 시 해제 |
| 발견 | 가장 가까운 적합 역할 1명만 조사, 나머지는 현재 행동 유지 |
| 채굴 | 드릴러 우선, 없으면 가장 가까운 굴착 가능 크루가 최대 6초 작업 |
| 후퇴 | 핑 반대편 또는 리더 쪽 안전지대로 이탈 |
| 방어 | 거너·엔지니어가 우선 집결하고 방어/설치 행동 가중치 상승 |
| 도움 | 가장 가까운 생존 AI 1명이 구조·호위, 필요하면 2명까지 참여 |
| 위험 | 해당 위치 반경 3타일을 5초간 회피 구역으로 등록 |
| 여기 | AI 행동을 강제하지 않고 관심 지점만 공유 |

- AI가 명령을 수락하면 작은 체크 표시와 음성/텍스트 반응을 1회 보낸다.
- 경로가 없거나 역할상 수행할 수 없으면 `이동 불가`, `대상 없음`을 짧게 표시하고 기존 행동으로 돌아간다.
- 동일 플레이어가 새 명령형 핑을 보내면 그 플레이어가 보낸 이전 `가자/공격/채굴/방어` 명령은 교체된다.

## 7. 도배 방지와 개인 제어

### 7.1 기본 제한

- 플레이어별 핑 충전량: **4회**.
- 핑 1회당 충전 1개를 쓰고 **2.5초마다 1개** 회복한다.
- 충전량이 0이면 휠은 열리지만 전송되지 않고, 남은 회복 시간을 휠 중앙에 표시한다.
- 10초 안에 6회 이상 전송을 시도하면 5초간 핑 전송을 잠근다.
- 도움 핑은 기절 상태에서 6초에 1회 별도 허용한다.

### 7.2 수신자 설정

- 파티원별 `핑 음소거`와 `핑 완전 숨김`을 제공한다.
- 완전 숨김 상태에서도 기절 구조 요청과 시스템 탈출 경고는 유지한다.
- 차단 여부는 개인 로컬 설정이며 다른 파티원에게 알리지 않는다.
- 호스트가 특정 플레이어의 핑만 서버 전체에서 차단하는 운영 기능은 1차 범위에서 제외한다.

## 8. 네트워크 규칙

핑은 게임 결과를 직접 바꾸지 않는 표현 데이터지만, 컨텍스트 대상과 도배 제한은 호스트 권위로 판정한다.

### 8.1 송신 데이터 초안

```text
ping {
  protocolVersion,
  pingId,
  senderSeat,
  type,
  worldX,
  worldY,
  targetKind?,
  targetId?,
  clientSentAt
}
```

### 8.2 처리 원칙

1. 클라이언트는 입력 즉시 자신의 화면에 임시 마커를 표시한다.
2. 호스트는 좌석, 좌표 범위, 대상 존재, 시야, 전송 제한을 검증한다.
3. 유효하면 호스트 시각과 정규화된 대상 정보를 포함해 전체에 전파한다.
4. 거부되면 송신자의 임시 마커를 조용히 제거하고 제한 사유만 짧게 표시한다.
5. 재접속한 플레이어에게는 남은 시간이 1초 이상인 현재 핑만 스냅샷으로 전달한다.
6. 핑은 저장 데이터나 리플레이 필수 상태에 포함하지 않는다.

### 8.3 예외 처리

- 호스트가 나가 승계되는 동안 새 핑은 로컬 임시 마커로 보관하고, 승계 완료 후 1초 이내의 핑만 재전송한다.
- 대상이 이미 파괴·습득·사망한 경우 위치 핑으로 낮춰 보내거나, 의미가 없으면 종료한다.
- 좌표는 현재 맵 경계 안으로 제한하고 `NaN`, 무한대, 비정상적으로 먼 좌표는 거부한다.

## 12. 검증 항목과 성공 기준

### 12.1 기능 검증

- 이동 중 `G` 휠을 열고 원하는 8방향 핑을 연속 20회 선택해 오입력이 2회 이하인지 확인한다.
- 좌·우클릭 홀드 중 핑 진입, `Esc` 취소, 창 전환, 사망, 카드 선택, 탈출 배치 모드에서 입력 상태가 꼬이지 않는지 확인한다.
- 2~4인 LAN에서 송신자, 좌표, 대상, 지속 시간이 모두 같은지 확인한다.
- 호스트 승계와 60초 재접속 후 낡은 핑이 부활하지 않는지 확인한다.
- AI가 위험 지역으로 돌진하거나, 수행 불가능한 명령에 영구 고착되지 않는지 확인한다.

### 12.2 플레이테스트 성공 기준

- 신규 플레이어의 80% 이상이 설명 후 30초 안에 기본 핑과 위험 핑을 보낼 수 있다.
- 10분 코옵 플레이에서 음성 없이도 `이동`, `위험`, `도움`, `채굴` 의도를 80% 이상 정확히 해석한다.
- 잘못 보낸 핑 비율이 전체의 10% 미만이다.
- 핑 때문에 사격·드릴 입력이 의도치 않게 유지되는 사례가 0건이다.
- AI 명령 수락 후 2초 안에 반응을 시작하는 비율이 90% 이상이다.
- 플레이어 1명당 평균 핑 횟수가 지나치게 적거나 많지 않은지 관찰하되, 목표 사용량을 보상으로 강제하지 않는다.

### 12.3 계측 이벤트 초안

ping_send(type, targetKind, distanceFromPlayer, viaQuickKey)
ping_cancel(reason)
ping_rejected(reason)
ping_acknowledge(type, latencyMs)
ai_ping_response(type, accepted, startLatencyMs, endReason)

### 14.3 핑 아이콘 아트 가이드

| 핑 | 권장 실루엣 | 피해야 할 표현 |
|---|---|---|
| 여기 | 중앙 점 + 바깥 파동 | 지도 핀만 사용해 `가자`와 혼동 |
| 가자 | 위로 뻗는 굵은 화살표 | 화면 밖 방향 화살표와 동일한 외곽선 |
| 공격 | 조준점 + 균열 또는 칼날 | 총기 전용 아이콘으로 특정 직업에 종속 |
| 발견 | 보석 + 빛살 | 별표만 사용해 희귀도 표시와 혼동 |
| 채굴 | 드릴 비트 또는 곡괭이 + 암반 | 드릴러 캐릭터 전용 장비 모양의 과도한 재현 |
| 후퇴 | 뒤로 꺾인 이중 화살표 | 아래 방향 화살표 하나만 사용 |
| 방어 | 방패 + 바닥 기준선 | 체력·방어력 버프 아이콘과 동일한 모양 |
| 도움 | 들어 올린 손 또는 구조 십자 | 회복 아이템의 의료 십자만 사용 |
| 위험 | 느낌표 + 삼각 균열 | 후퇴 핑과 같은 경고 삼각형만 사용 |

- 32px 표시에서도 내부가 뭉개지지 않도록 큰 덩어리 1~2개로 구성한다.
- 외곽선 두께는 128px 원본 기준 8~10px로 통일한다.
- 아이콘 내부의 빈 공간을 충분히 두고, 작은 글자나 세밀한 광물 결은 넣지 않는다.
- `공격/위험/후퇴`, `가자/여기`, `발견/채굴`은 색을 제거한 흑백 상태에서도 실루엣만으로 구분되어야 한다.

|---|---|---:|---|
| `ping-pop-in` | 70% → 115% → 100% 스케일, 페이드인 | 160ms | 월드 마커, 화면 밖 아이콘 |
| `ping-ring-out` | 바닥 링 확대 + 페이드아웃 | 450ms | 일반 핑 |
| `ping-danger-pulse` | 강한 2회 펄스 | 620ms | 위험, 후퇴 |
| `ping-wheel-select` | 선택 쐐기 4px 팽창 + 아이콘 상승 | 90ms | 핑 휠 |
| `ping-ack` | 체크가 튀며 나타난 뒤 축소 | 300ms | 동의, AI 수락 |
| `ping-fade-out` | 위로 4px 이동 + 페이드아웃 | 220ms | 마커, 로그, AI 응답 |

모션 감소 설정에서는 모든 스케일·이동을 제거하고 80ms 페이드로 대체한다.

## 14. 구현 메모 (2026-09-02 · 1차 MVP)

- 구현 파일: `ping/tc-ping.js` (모듈) · `ping/inject-ping.mjs` (주입기). 적용본: `tunnel-crew-infinite-mode-v7.8.1-ping.html`.

- 구현 범위: §2 조작(G 탭·G 홀드 휠·V, Esc/우클릭 취소, blur 취소, 홀드 중 장비 입력 차단) · §3 8종 휠 · §4 컨텍스트(적·보스/광맥·암반/기절 크루/탈출 포트/미탐사) · §5 마커·화면 밖 화살표(최대 3)·3줄 로그·의미별 음형 · §6.1 스택·동의·송신자 취소 · §6.2 AI 9종 반응 · §7 충전 4/2.5초, 6회/10초 잠금, 기절 시 도움 핑 6초 · §7.2 핑 음소거·완전 숨김(설정) · §8 `{t:'ping'}` 릴레이 · §9 팀 핑 음량 슬라이더 · §10 첫 안내 토스트·Tab 키 가이드 · §12.3 계측은 `TCPING.events` 에 적재.
- 검증: 무한 모드 + AI 크루 런에서 탭/휠/V/취소/동의/광맥 컨텍스트/AI goal 주입(가자·채굴·도움·발견) 확인. 코옵 서버(5488)에 호스트·게스트 소켓 2개를 붙여 릴레이 송수신 확인.
- 2차로 미룬 것: 호스트 권위 검증(현재는 수신자 전원이 같은 규칙으로 검증), 재접속 스냅샷·호스트 승계 재전송, 파티원별 음소거, 키 재지정, 컨트롤러, 좌우 팬, 아이콘 실루엣 아트.
- AI 크루의 자발적 핑(관전 연출, 2026-09-02): AI 도 자기 상황에 맞는 핑을 가끔 보낸다 — 교전 중 `공격`(보스·정예는 `위험`), 광맥 채굴 시 `발견`→`채굴`, 플레어 `여기`, 설치물 `방어`, 구조 이동 `도움`, 기절 시 6초마다 `도움`, 먼 합류·탈출 이동 `가자`. 멤버별 10~22초 쿨다운, 전역 4초 간격, 상황 지속 중 초당 35% 확률. 표시·로그·소리만 내고 사람의 충전을 쓰지 않으며 다른 AI 에 명령으로 작동하지 않고 코옵으로 보내지 않는다. 사람 핑을 수행 중일 때는 되받아 핑하지 않는다. 튠은 `TCPING.aiPing`.
