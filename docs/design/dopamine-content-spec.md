# Phase 5 — 도파민 심리학 설계서

> 작성: 2026-08-31 01:30 · 근거: 01-steam-trends.md(T1~T7), 02-strength-weakness.md 우선순위

## 5.1 심리학 프레임 → 적용점

- **변동비율 강화(VR schedule)**: 보상 간격이 예측 불가할 때 행동 반복이 가장 강하다. → 채굴(rare 파괴)에 낮은 확률의 '노다지' 분산을 추가. 단, **피티 카운터**로 장기 기대치는 안정시켜 좌절 방지.
- **보상 예측 오차**: 도파민은 '예상보다 좋음'에서 나온다. → 노다지는 예고 없이, 그러나 발동 순간의 연출 대비를 극대화(화면 킥+금색 링+전용 스팅).
- **근접 실패(near-miss)**: 이월 항목(니어미스 유물)에 배정. 인위 조작 금지 — 실제 확률 그대로.
- **자기결정이론(SDT)**: 유능감 = 콤보·피버(내 손으로 만든 흐름), 관계성 = 정산 기록(활약의 목격), 자율성 = 이월 항목(탈출 배당·개인 계약).
- **몰입(Flow)**: 피버는 '연속 굴착'이라는 이미 하고 있는 행동에 게이지를 달아 흐름을 가시화 — 새 조작을 요구하지 않는다.
- **절정-종결 법칙(peak-end)**: 정산 카운트업 + 원정 기록 카드로 종결부 밀도를 올린다. 실패 정산도 '기록'을 남겨 종결 감정을 회수.
- **사회적 목격**: 웃긴 사인(死因) 문구는 스크린샷/클립 유발 장치 — 실패의 바이럴화(T3).

## 5.2 고유 동사 결합 원칙

범용 슬롯머신化 금지. 모든 장치는 **채굴·어둠·협동·탈출**에 결합한다:
잭팟은 뽑기가 아니라 **파고 있던 광맥에서** 터진다. 피버는 버튼이 아니라 **굴착 리듬**에서 나온다. 기록은 로비가 아니라 **원정의 결과**로 남는다.

## 5.3 구현 확정 콘텐츠 (v7.8.0 사이클 1~3)

### 사이클 1 — 광맥 잭팟 "노다지" (VR + 예측오차 · 채굴)

- **트리거**: rare 블록(ore/gem/crys) 파괴 시 확률 3.5% + 피티(불발마다 +0.9%p, 발동 시 리셋). 기대 발동 간격 ≈ rare 12~15개당 1회.
- **보상**: 코어 +(4~7)×coreMult — 즉시 지급이 아니라 **0.12초 간격 순차 지급**(카운트업, 개당 +1 텍스트+ore 틱). 채집 XP 보너스.
- **리스크 동반**: 발동 시 spawnDebt +5 — 노다지 소리가 적을 부른다(공짜 잭팟 금지, 긴장 유지).
- **연출**: J.kick(7) + 금색 링 2중 + SFX.dawn, '노다지!' 대형 텍스트, toast.
- **엣지**: 블록 연쇄(blast) 중 발동 허용(카운터는 동일), 사망/정산 중 지급 중단(큐가 play 페이즈에서만 소비).

### 사이클 2 — 피버 드릴 (Flow + 즉시 피드백 · 채굴)

- **게이지**: 블록 파괴 간격 2.4초 이내면 콤보 유지·증가. 10콤보마다 'x N' 텍스트.
- **발동**: 25콤보 도달 시 피버 6초 — 굴착력 ×1.5, 이동 ×1.1, 벽 파괴 시 소형 파쇄 폭발(반경 1.2). 종료 후 재발동 대기 30초.
- **연출**: 화면 금색 비네트(DOM 오버레이 — update 정지와 무관), SFX.ready 스팅, 시작/종료 toast.
- **엣지**: universalBlastLock 게이트로 연쇄 폭발 재귀 차단. 피버 중 사망 시 배율 원복은 다음 런 리셋(infResetBuild)이 보장. 레벨업 카드 배율과 곱연산 — 시작 ×1.5 / 종료 ÷1.5로 안전.

### 사이클 3 — 원정 기록 + 웃긴 사인 + 정산 카운트업 (peak-end + 목격 + T3)

- **runStats**: kills / jackpots / jackpotCores / maxCombo / fevers / relicsFound를 런 중 누적.
- **결과 화면**: "이번 원정의 기록" 행 추가 — 최대 콤보·노다지·피버·처치·유물. 전멸 시 사인 문구를 상황 기반으로 생성(보스전 중·심층·콤보 중 등) — 자학 유머 톤, 예: "지층 3에서 노다지를 눈앞에 두고 산화".
- **정산 카운트업**: ledger 4칸 숫자를 0→N 순차 카운트업(40ms 틱, 800ms 완료, 칸당 120ms 지연 순차 시작), 5틱마다 SFX.tick, 완료 시 SFX.cache. `prefers-reduced-motion` 시 즉시 표시.

## 5.5 남용 방지 가드레일

1. 도박성 장치는 **게임 내 재화만** — 현금·외부 가치 연결 절대 금지.
2. 근접실패 인위 조작 금지 — 표시 확률 = 실제 확률. 피티는 플레이어에게 유리한 방향으로만 작동.
3. 연출 빈도 상한 — 잭팟 기대 간격 12회+, 피버 재사용 대기 30초. 화면 점멸은 `prefers-reduced-motion` 존중.
4. 잭팟은 반드시 리스크(적 웨이브) 동반 — 무비용 보상 루프 금지.
5. 세션 연장 강요 장치(일일 보상, FOMO 타이머) 도입 금지.
