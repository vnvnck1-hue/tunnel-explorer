# FTUE — 「응답 없는 4번 갱도」 제작 기준

## 목표

첫 원정은 튜토리얼 전용 훈련장이 아니라 본편에 남는 실제 사건이다. 플레이어는 구조 신호를 따라 내려가 이동·굴착·시야·전투·크루·탈출을 스스로 수행하고, 선발대의 블랙박스와 그 신호를 흉내 내는 지하 생명체의 존재를 알게 된다.

## 연출 계약

- 실제 플레이 80%, 컷만화 15%, 실시간 카메라 연출 5%.
- 영상 파일은 쓰지 않는다. 컷만화는 Unity 카메라 공간 UI에서 실시간으로 합성한다.
- 컷만화는 흰 종이 배경이 아니라 완전한 검정 배경에 올린다.
- 각 컷은 한번에 나오지 않고 0.12~0.24초 진입 애니메이션으로 순차 등장한다. 이미 등장한 컷은 화면에 남는다.
- 각 컷의 첫 프레임에 전용 효과음·무전 신호·음악 라우팅을 동기화한다.
- 말풍선은 원화에 굽지 않고 Unity가 그린다. 대사 수정·접근성·다국어화를 그림 교체 없이 처리한다.
- 조작권을 빼앗는 시간은 전체 8초 미만. 대화 대부분은 이동 중에 재생한다.
- 한 번에 요구하는 입력은 하나다. 상황을 먼저 보여준 뒤 3초 정체하면 키 안내를 띄운다.
- 첫 생환 전에는 메인 메뉴의 무한 모드·성장·유물·관전을 잠근다. 설정과 종료는 항상 열어 둔다.
- 핵심 행동이 12초 이상 정체되면 환경 힌트, 22초면 목표 윤곽선, 35초면 크루의 직접 힌트를 순차로 추가한다.
- Esc 길게 누르기로 컷만화를 건너뛸 수 있고, 설정의 감속 모드에서는 진입 스케일·흔들림을 축소한다.

## 그래픽 톤 락

기준 원화: [`ftue-cartoon-level-1.png`](../concept-art/ftue-cutscene/ftue-cartoon-level-1.png)

모래 앵커: [`ftue-morae-character-anchor.png`](../concept-art/ftue-cutscene/ftue-morae-character-anchor.png)

- **장르:** 절제된 시네마틱 카툰. 성숙하지만 무겁거나 실사적이지 않다.
- **선:** 중간 굵기의 먹선. 인물·도구 실루엣에만 강하게, 먼 배경은 부드럽게.
- **형태:** 인체는 약 5.5~6등신. 헬멧·장갑·공구는 10~18% 과장하되 치비로 가지 않는다.
- **재질:** 넓은 색면 + 2~3단 셀 음영. 긁힘·먼지는 가장자리에만 선택적으로.
- **팔레트:** 지하의 깊은 보라·석탄색, 작업복의 머스터드, 램프의 암버, 생명체의 제한된 진홍.
- **빛:** 사진적 미세 반사를 버리고 큰 명암 덩어리로 공간을 읽힌다.
- **인물 고정 요소:** 모래는 머스터드 작업복, 왼쪽 팔·백팩 손잡이의 청록 테이프, 오른쪽 바이저 금, 수직 환기구 2개인 사각 백팩을 모든 컷에서 유지한다.
- **금지:** 포토리얼, 광택 3D, 밀리터리 리얼리즘, 애니메 미소녀 비례, 과도한 치비, 전면적인 적색 필터.

## 컷만화 시퀀스

1. **강하선 충돌** — 3컷, 8~10초. 안전봉을 잡은 손 → 비상등 아래 크루 → 충돌.
2. **블랙박스 기록** — 5컷, 15~18초. 작업 → 움직이는 광맥 → 벽 뒤 공간 → 송신기 손 → 헬멧 반사.
3. **지층 각성** — 2컷, 7~9초. 크루와 지하 실루엣의 단면 → 벽 균열을 타고 올라오는 열.
4. **강하선 문** — 4컷, 10~13초. 탑승 → 반쯤 닫힌 문 → 모래의 바이저 → 문·타이틀.

## 비언어 무전음

- **관제:** 높고 정확한 2음, 균일한 박자.
- **모래:** 낮고 짧은 3음, 약간 불규칙.
- **선발대장:** 중저음 펄스 + 테이프 노이즈.
- **흉내 내는 신호:** 모래의 음형을 느리게 늘이고 순서를 뒤집은 잔향.
- 대사 중에는 BGM -6 dB, 비핵심 SFX -3 dB. 무전 필터는 350~3,500 Hz 대역을 중심으로 하되 자막 없이 뜻을 들어야 하는 음성은 사용하지 않는다.

| 콜드 오픈·장비 선택 | 45초 | 20초 | 선택 강조·기본 드릴러 추천 |

| 첫 전투 | 60초 | 45초 | AI 엄호·적 체력 단계 감소 |
