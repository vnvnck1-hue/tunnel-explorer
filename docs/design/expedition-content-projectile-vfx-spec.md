# 땅굴 크루 — 원정 콘텐츠·장비·개인 계약·필드 도감·투사체 VFX 기능 명세

> 작업 브랜치: `codex/expedition-content-projectile-vfx`
> 대상: Unity 본편 `unity/TunnelCrew/`
> 원칙: 선택과 발견은 늘리되, 이동 왕복·강제 대기·실패 시 진행 초기화·과도한 메뉴 조작은 만들지 않는다.

## 1. 목표

이번 작업은 다음 네 콘텐츠 축과 전투 표현을 하나의 원정 구조로 묶는다.

1. 원정 목표 다양화 — 같은 지형에서도 플레이 동사가 달라진다.
2. 직업별 대체 장비 — 수치가 아니라 조작과 전투 리듬이 달라진다.
3. 개인 위험 계약 — 팀을 방해하지 않는 선택적 위험/보상이다.
4. 필드 도감 — 발견과 전투가 영구 기록으로 남는다.
5. 투사체 VFX — 발사체별 실루엣·색·속도감·착탄 반응을 구분한다.
6. 성능 예산 — CRT와 신규 VFX가 동시에 켜져도 안정적인 프레임을 지킨다.

## 2. 원정 목표

### 2.1 목표 타입

| ID | 이름 | 핵심 행동 | 완료 규칙 | 불편 방지 규칙 |
|---|---|---|---|---|
| `breach` | 심층 돌파 | 자유 굴착 | 현재 장악도 목표 도달 | 기존 모드 유지, 기본 선택 |
| `core_recovery` | 공명 코어 회수 | 표시된 특수 광맥 굴착 | 공명 광맥 3개 파괴 | 접근 가능한 벽만 선정, 서로 너무 멀리 배치하지 않음 |
| `survey` | 지질 측량 | 표시된 빈 공간 방문 | 측량점 3개에서 각 1.25초 체류 | 진행도는 이탈해도 보존, 피격 리셋 없음, 순서 강제 없음 |

목표 완료 뒤 보스를 소환한다. 목표 외 일반 굴착도 자원·XP·위협도에 계속 기여한다.

### 2.2 선정과 표시

- 행성 지도에서 좌우는 행성, 상하는 임무를 선택한다.
- 임무를 선택하지 않으면 `심층 돌파`가 기본이다.
- 각 목표는 HUD에 `행동 + 현재/필요` 한 줄로 표시한다.
- 목표 위치는 월드 마커로 보이되 미탐색 영역 전체를 노출하지 않는다. 가까워지거나 정찰 효과에 들어오면 정확한 위치를 표시한다.
- 측량과 코어 회수는 막다른 길 왕복을 줄이기 위해 진입점에서 도달 가능한 후보 중 거리 사분위가 겹치지 않게 고른다.

## 3. 직업별 대체 장비

장비는 출격 전 직업 화면에서 한 번 고른다. 런 도중 교체하지 않아 카드 선택과 제작 휠의 인지 부담을 늘리지 않는다.

| 직업 | 기본 장비 | 대체 장비 | 행동 변화 | 대가 |
|---|---|---|---|---|
| 드릴러 | 고압 중형 드릴 | 충격 코어 드릴 | 느린 타격, 넓은 벽 피해·큰 적 경직 | 열과 공격 간격 증가 |
| 거너 | 벨트식 중화기 | 파쇄 산탄기 | 근거리 다발탄·강한 넉백 | 사거리·탄창 감소 |
| 스카우트 | 정찰 카빈 | 관통 레일 카빈 | 느린 단발, 직선 관통·표식 | 연사력 감소 |
| 엔지니어 | 서비스 총기 | 코일 리피터 | 전력 노드 주변에서 도탄·감전 강화 | 노드 밖 기본 위력 감소 |

초기 구현은 데이터와 발사 패턴을 먼저 연결한다. 전용 애니메이션·장비 스프라이트는 후속 아트 슬롯으로 둔다. 선택하지 않은 기본 장비의 현재 감각은 변하지 않는다.

## 4. 개인 위험 계약

### 4.1 설계 원칙

- 계약 실패는 기본 보상이나 팀 보상을 깎지 않는다.
- 계약 때문에 팀 목표를 늦추거나 다른 플레이어 자원을 훔치게 하지 않는다.
- 플레이어가 선택하지 않으면 기존 난이도와 경제가 유지된다.
- 런 중 조건을 더 이상 달성할 수 없어도 패널티 없이 `미완료`로 끝난다.

### 4.2 계약 세트

| ID | 이름 | 조건 | 보상 | 실패 처리 |
|---|---|---|---|---|
| `hot_drill` | 과열선 작업 | 열 70% 이상에서 벽 12개 파괴 | 귀환 코어 +2 | 없음 |
| `close_quarters` | 근접 교전 | 2.2칸 안의 적 16마리 처치 | 귀환 코어 +2 | 없음 |
| `pathfinder` | 선발 측량 | 신규 구역 10곳 발견 | 귀환 코어 +2 | 없음 |
| `untouched` | 무결점 장비 | 한 지층에서 큰 피해 없이 보스 격파 | 귀환 코어 +3 | 피격 시 일반 계약으로 자동 전환하지 않고 미완료 표시 |

한 원정에 하나만 선택한다. 첫 구현에서는 직업과 잘 맞는 추천 계약을 기본 포커스로 두되 자동 수락하지 않는다.

## 5. 필드 도감

도감 카테고리는 `생물 / 지질 / 장비 / 원정 기록` 네 가지다.

- 생물: 첫 조우 시 실루엣, 첫 처치 시 이름·행동, 누적 처치로 추가 생태 설명.
- 지질: 해당 광물을 처음 채굴하면 등록.
- 장비: 실제 사용한 장비와 제작품을 등록.
- 원정 기록: 임무 최초 완료, 보스 최초 격파, 계약 최초 완료.
- 새 항목은 런 중 작은 토스트만 표시하고 상세 화면을 강제로 열지 않는다.
- 중복 발견은 알림을 만들지 않는다.
- 도감 완성은 전투력을 직접 올리지 않고, 소량 코어·칭호·외형 보상으로 연결한다.

저장은 기존 `MetaState`에 안정적인 문자열 ID 집합으로 추가한다. 알 수 없는 ID는 보존해 향후 콘텐츠 버전과 세이브 호환성을 유지한다.

## 6. 투사체 비주얼 언어

| 분류 | 형태 | 색 | 궤적/착탄 |
|---|---|---|---|
| `standard` | 짧은 리벳 탄심 | 백색+황금 | 가는 감쇠 꼬리, 작은 방향성 스파크 |
| `multi` | 짧고 넓은 파편 | 주황 | 산개가 읽히는 짧은 꼬리 |
| `pierce` | 긴 바늘형 랜스 | 청백 | 긴 잔광, 관통 시 전방 스파이크 |
| `ricochet` | 마름모 펄스 | 보라 | 벽 착탄 시 각진 링 |
| `explosive` | 두꺼운 플라즈마 캡슐 | 적주황 | 팽창 링·불꽃·연기 |
| `rain` | 고온 중탄 | 적색+황금 | 무거운 섬광과 파편 |
| `laser` | 매우 긴 에너지 빔 | 청록+백색 | 순간 별광·큰 충격 링 |
| `support` | 둥근 펄스 | 민트 | 작은 전자 링, 카메라 흔들림 없음 |
| `shard` | 결정 파편 | 민트+백색 | 짧은 결정 스파크 |

한 투사체는 공용 절차 셰이더를 쓰며 `SpriteRenderer` 하나로 코어·헤일로·꼬리를 함께 그린다. 발사마다 머티리얼을 만들지 않고 공유 머티리얼과 색상만 사용한다.

타격감은 발사 반동, 탄속 실루엣, 착탄 파티클, 적 피격 반응을 조합한다. 연사 무기는 매 발 큰 히트스톱이나 카메라 흔들림을 주지 않는다.

## 7. 성능 예산과 저사양 정책

### 7.1 예산

- 활성 플레이어 투사체: 표시 96개 상한.
- 투사체 렌더러: 풀 재사용, 런 중 생성·파괴 0을 목표.
- 투사체 착탄: 일반 3~5입자, 강탄 8~18입자.
- 월드 파티클: 시스템별 최대 800이 아니라 실제 효과 특성에 맞춰 240~560으로 제한.
- 절차 도형 FX: 96개 상한, 초과 시 가장 오래된 효과 재사용.
- CRT 지속광 히스토리: 1440p 초과에서 1/2 해상도 유지. 지속광이 꺼지면 RT 즉시 해제.
- 매 프레임 GC: CRT 렌더 패스와 투사체 렌더 경로 모두 0B 목표.

### 7.2 품질 단계

| 품질 | 투사체 | 착탄 | CRT |
|---|---|---|---|
| Ultra | 전체 꼬리·헤일로 | 전체 | 전체 효과 |
| Normal | 전체 실루엣 | 입자 75% | 지속광 히스토리 고해상도 규칙 유지 |
| Low | 꼬리 길이 75% | 입자 50%, 연기 축소 | afterglow·RF snow 비용 축소 |
| Photosensitive | 섬광 알파 제한 | 큰 플래시 제거 | 강한 깜빡임·롤·노이즈 제한 |

## 8. 검증 기준

- 세 목표가 서로 다른 행동으로 완료되고 완료 전 보스가 나오지 않는다.
- 목표 셀이 접근 불가능하거나 이미 빈 셀로 선정되지 않는다.
- 기본 장비를 선택하면 기존 전투 테스트 결과가 유지된다.
- 계약 미수락·실패가 기존 정산량을 감소시키지 않는다.
- 동일 도감 항목은 한 번만 신규 알림을 낸다.
- 각 투사체 분류가 정지 화면에서도 색뿐 아니라 길이·폭·착탄 모양으로 구분된다.
- 100개 투사체 스트레스에서 렌더러와 머티리얼 수가 매 프레임 증가하지 않는다.
- CRT on/off와 지속광 on/off에서 임시 렌더 텍스처가 누적되지 않는다.
