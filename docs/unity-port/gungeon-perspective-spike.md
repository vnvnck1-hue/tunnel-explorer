# 메인 런 3D 공간감 렌더러

Godot 건전 프로토타입의 코드나 자산을 포팅한 것이 아니다. 그 문서에서 확인한
`실제 높이의 벽 + 좁은 FOV + 틸트 카메라 + 빌보드 캐릭터` 원리를 TunnelCrew 메인 런의
실제 `WorldGrid` 데이터와 런타임 액터에 적용한 표현 계층이다.

## 실행

1. Unity에서 `Assets/_Project/Scenes/Run.unity`를 실행한다.
2. 3D 월드 렌더러가 기본으로 활성화된다.
3. 에디터/Development Build에서 **F3**은 기존 2D 표시로 즉시 폴백하는 안전 스위치다.
4. **`[` / `]`**는 후보 카메라 각도를 임시 비교한다. 최종 각도는 아직 확정하지 않았다.

`RunBootstrap` 의 `_perspectiveWorld`를 끄면 코드 삭제 없이 기존 2D 본선으로 되돌아간다.
PlayerPrefs, 저장 데이터, 시뮬레이션, 충돌, F8/F9 투영 프리셋은 변경하지 않는다.

## 현재 본선값

- 실제 메인 런의 플레이어 주변 `17 × 13`셀을 읽는다.
- 빈 셀은 바닥, 고체 셀은 높이 `1.45`의 벽 윗면과 노출 측면으로 만든다.
- 카메라는 FOV `28°`, 거리 `22`의 원근 카메라다.
- pitch 후보 세 개는 임시 비교용이다: `A 55°` → `B 60°` → `C 65°`.
- 시작값은 `A 55°`이며 선택값은 저장하지 않는다.
- `480 × 270` RenderTexture를 Point 필터로 확대한다.
- 플레이어·크루·적은 표현 계약(`PerspectiveActors`)으로 온다. 뷰가 시뮬레이션 바닥 좌표·높이·프레임·틴트를
  직접 제출하므로 청록색 대체판과 플레이어 전용 빌보드는 없앴다.
- 아직 계약으로 옮기지 않은 투사체·이펙트·소품만 `SpriteRenderer` 미러가 그린다(5단계에서 제거).
  계약으로 올라온 원본은 미러에서 자동으로 빠져 이중으로 그려지지 않는다.
- 영역 외 액터는 숨기고 레거시 미러의 소스 목록은 0.25초 간격으로 갱신한다.

## 분리해 둔 것

- `ReferenceTopDown`이나 F8/F9 투영 프리셋 변경
- 기존 2D 환경 렌더러 삭제
- 2D 조명을 3D 조명으로 이주
- Godot 프로토타입 파일 또는 자산 참조

카메라 각도·벽 높이·재질·조명은 시뮬레이션과 분리된 표현 계층에서 후속 튜닝한다.
