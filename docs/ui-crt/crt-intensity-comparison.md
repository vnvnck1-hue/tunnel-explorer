# CRT 화면 왜곡 강도 비교안

기준: 필드 원색 유지, 황색 인광은 HUD에만 적용, 월드와 HUD를 합친 최종 컬러 버퍼에 동일한 CRT 패스를 적용한다.

> 이 문서는 초기 강도 시안과 승인 이미지를 보존한 레퍼런스다. 2026-09-12 후속 요청으로 실제 게임 선택지는 서로 다른 방식의 모니터 5종으로 바뀌었다. 현재 프리셋·조작·리소스는 [런타임 안내](crt-display-runtime-guide.md)를 따른다. Surveyor가 Strong− 기준을 계승하되 기본 잔상은 Off이며, 잔상은 Abyss에서만 사용한다.

## 승인 결정

- 디자인 기준 이미지: [`crt-intensity-02-strong.png`](img/crt-intensity-02-strong.png)

## 권장 운용

- 상시 화면은 1단계와 2단계 사이의 `Strong−`를 사용한다.
- 3단계는 저체력, 심층 진입, 신호 불안정처럼 상태를 전달할 때 짧게 사용한다.
- 4단계는 피격 순간이 아니라 EMP, 보스 등장, 이상지대 진입 같은 큰 사건에만 사용한다.
- 5단계는 플레이가 어려우므로 전환 프레임에서만 순간적으로 사용한다.
- 강도 전환은 셰이더 키워드를 바꾸지 않고 하나의 프로파일 보간으로 처리한다.
- UI만 예외 처리하지 않는다. HUD Canvas까지 합성된 최종 버퍼를 왜곡해야 아이콘과 패널도 필드와 함께 휜다.

## 구현 방법 조합

1. **항상 켜진 기본층:** 곡률, 스캔라인, 외곽 비네트, 미세 RGB 분리.
2. **시간 변화층:** 블루 노이즈, 밝기 롤, 크로마 크롤. 광과민 모드에서는 정지 또는 제거한다.
3. **이벤트층:** 좁은 수평 UV 오프셋 밴드, 짧은 고스팅, 수직 홀드 오류.
4. **고급층:** 이전 프레임 RenderTexture를 이용한 인광 잔상. Strong 이상에서만 사용한다.

기본층과 이벤트층을 분리하면 평상시 가독성을 유지하면서 특정 상황에서 3~5단계로 빠르게 상승시킬 수 있다.

## 상시 화면 제한

- 강한 동기선은 상시 고정하지 않고 낮은 알파로 간헐적으로만 통과시킨다.
- 월드와 HUD에 동일한 UV 왜곡을 적용하되 조준 정확도와 입력 좌표 계산은 왜곡 전 좌표를 유지한다.
- 화면 가장자리 잘림은 `safeAreaInset`으로 보정하며 UI를 역왜곡해 곧게 펴지 않는다.
- 이벤트가 끝나면 150~300ms 동안 `Strong−`로 복귀한다.
