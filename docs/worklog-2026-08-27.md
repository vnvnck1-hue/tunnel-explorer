## 한 줄 요약

무한 모드 본편을 v7.1.7까지 갱신하고, 붉은 화염룡의 등장·대기·이동 애니메이션과 드릴 사운드, 직업 특성 카드 및 드릴러 전용 특성 트리를 연결했으며 오래된 데모와 중복 스프라이트를 정리했다.

---

## 완료된 작업

### 1. 무한 모드 본편 갱신

- `tunnel-crew-infinite-mode-v7.1.6.html`에 당일 중간 작업 상태를 정리했다.
- `tunnel-crew-infinite-mode-v7.1.7.html`에 최신 게임 상태를 통합했다.
- 특성 카드의 프레임·아이콘·텍스트를 독립 깊이 레이어로 구성하고 마우스 추적, 광택, 등급별 연출과 반응형 텍스트 맞춤을 적용했다.
- 드릴러 전용 3분야 15노드 특성 트리와 초기화, 포인트 획득, 실제 드릴·균열·돌파 효과 연결을 추가했다.
- 보스 붉은 화염룡이 이동 여부에 따라 대기/걷기 프레임 애니메이션을 사용하도록 연결했다.

### 2. 붉은 화염룡 애니메이션 리소스

- 등장 8프레임과 남서 이동 8프레임을 투명 PNG로 구성했다.
- 외부 대기/이동 GIF의 흰 배경을 제거해 투명 GIF로 변환했다.
- 대기 37프레임과 이동 37프레임을 런타임에서 직접 사용할 수 있도록 분리했다.
- GIF 조립 및 흰 배경 제거 도구를 추가했다.
- 디자인 가이드에 45도 버드뷰 고정, GIF 우선 제작, 방향 재활용, 투명화 규칙을 기록했다.

### 3. 드릴 사운드와 등장 연출

- 드릴 시작·루프·해제 사운드를 다듬어 본편에 사용할 수 있도록 정리했다.
- 붉은 화염룡 등장 8프레임과 GIF를 제작하고 게임 자산으로 추가했다.

### 4. 특성 시스템 기획 확장

- 공용 18개와 직업별 36개 노드를 기준으로 특성 노드 시스템 v0.2를 정리했다.
- 재화, 점진 공개, 구매·환불, 캡스톤, 코옵 분배, 접근성, 데이터 경계와 단계별 구현·검증 계획을 명시했다.
- 기존 드릴러 v0.1 노드의 v0.2 이관 위치를 기록했다.

### 5. 저장소 정리

- 더 이상 사용하는 본편이 아닌 `demos/`의 실험 HTML을 제거했다.
- 중복된 엔지니어 레이어 스프라이트와 백업 스프라이트를 제거했다.
- 과열 실험용 이미지와 레거시 데모 파일을 정리했다.

## 검증

- Git 변경 목록과 대용량 파일을 점검했다. GitHub 단일 파일 제한(100MB)을 넘는 파일은 없다.
- 붉은 화염룡 프레임 수와 PNG/GIF 출력 파일 존재 여부를 확인했다.
- Python 제작 도구는 `py_compile`로 문법을 확인했다.
- 본편 HTML의 인라인 스크립트는 별도 추출 후 Node.js 문법 검사로 확인했다.
