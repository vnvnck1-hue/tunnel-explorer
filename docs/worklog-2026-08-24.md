## 완료된 작업

### 1. 메인 메뉴 & LAN 코옵 진입
- 시작 화면을 **메인 메뉴**로 변경
  - **솔로 미션** / **LAN 코옵 (테스트)**
- 코옵 로비는 부팅 시 자동 오픈하지 않고, 메뉴에서만 진입
- 역할/결과/로비에서 메인으로 복귀 가능
- 관련: `coop/client.js`, `coop/server.mjs`, `coop/README.md`

### 2. M1 — 솔로 보조 드론
역할별 고정 모드 1기 (코옵에서는 OFF)

| 역할 | 드론 |
|------|------|
| 드릴러 | 조명 |
| 스카웃 | 채굴 |
| 엔지니어 | 사격 |
| 거너 | 채굴 |

### 3. M2 — 미션 3종
솔로 흐름: **미션 선택 → 바이옴 → 역할 → 플레이**

| 미션 | 목표 |
|------|------|
| 채취 | 광물 N개 후 탈출 |
| 회수 | 유물 운반 후 탈출 (쓰러지면 드롭·리스폰) |
| 소탕 | 엘리트 1마리 처치 후 탈출 |

- LAN 코옵은 당분간 **채취 + 퍼플** 고정

### 4. M3 — 바이옴 2
| 바이옴 | 내용 |
|--------|------|
| 퍼플 땅굴 | 기존 딥퍼플 팔레트 |
| 청록 염굴 | 쿨톤 팔레트 · 적 틴트 · **염수 장판 DoT** |

### 5. M5 — UX / 사운드 / 튜토리얼
- 첫 솔로용 **약 30초 조작 가이드** (건너뛰기 / 메뉴에서 재실행)
- 메뉴·인게임 **소리 ON/OFF**
- 탈출 가능 신호, 결과 화면 재도전 팁
- SFX: 시작 / 탈출 가능 / 실패 / 시간 초과 등

### 6. BGM
- 땅굴용 절차적 BGM을 **신비·스산** 톤으로 재작성
- 클릭 후 AudioContext resume → 즉시 kick + 루프
- 볼륨/음역 보정 (노트북 스피커에서도 들리도록)
- **소리 ON**: 첫 클릭은 BGM 시작, 이후 음소거 토글

### 7. 기타 수정
- 메뉴 버튼 무반응: `paintMuteUI` 문법 깨짐으로 스크립트 전체 중단 → 복구
- 드릴러 스프라이트 좌향 드릴 프레임 플립 등 (이전 세션에서 이어진 데모 개선 포함)

## 실행 방법

### 솔로
`demos/tunnel-crew-loop-demo.html`를 코옵 서버로 열거나 정적 서버로 연다.

### LAN 코옵
```bash
cd coop
npm install
npm start
```
- 호스트: `http://127.0.0.1:5188/demos/tunnel-crew-loop-demo.html`
- 게스트: `http://<LAN-IP>:5188/demos/tunnel-crew-loop-demo.html`
