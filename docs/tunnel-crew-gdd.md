# 땅굴 크루 (가칭) — 게임 기획서 v0.1

> **한 줄 포지션**  
> Core Keeper식 **2D 타일 채굴·시야 비주얼** + Deep Rock Galactic식 **4역할 코옵**을  
> **라이트 미션 런(10~20분)** 으로 압축한 지하 탐험 게임.

**문서 목적:** 전체 방향 고정 → 코어루프 데모로 재미 검증 → 본편 확장  
**관련 프로토:** `tunnel-explorer-lab.html` (기존 FoW/LOS/드릴/적 실험 자산 활용)

---

## 1. 비전 & 플레이 판타지

### 1.1 플레이어가 느끼는 것
- 어두운 땅굴을 **역할별로** 파고·비추고·막고·밀어붙이며 목표를 깬다.
- “혼자 다 하는 샌드박스”가 아니라 **짧은 팀 미션**.
- 한 판이 끝나면 정산하고, 다음 미션으로 가볍게 다시 들어간다.

### 1.2 벤치마크에서 가져오는 것 / 버리는 것

| 출처 | 가져옴 | 버림 (라이트화) |
|------|--------|----------------|
| Core Keeper | 탑다운 2D 타일, 채굴 손맛, FoW/횃불, 자원 드롭 비주얼 | 거대 크래프트, 농사·자동화, 영구 월드 육성 |
| Deep Rock Galactic | 4역할 상호의존, 미션 목표, 짧은 런·탈출 | 복잡한 과금형 메타, 헤비 시뮬, 긴 미션 브리핑 |

### 1.3 성공 기준 (제품)
- **솔로 1인**으로도 한 판이 성립 (역할 1 + 간이 보조).
- **2~4인**일 때 역할이 체감된다 (없으면 불편한 정도가 분명).
- “한 판 더”가 나오는 **코어루프**가 데모에서 먼저 증명된다.

---

## 2. 코어 루프

```
역할 선택 → 하강(미션 시작)
  → 탐험(채굴 / 시야 / 이동)
  → 위협(적) 대응
  → 목표 달성(채취·회수·처치 중 1)
  → 탈출(입구/드롭포드)
  → 짧은 정산 → 다음 미션
```

### 2.1 한 판 길이
- 목표: **10~20분**
- 실패: 전멸 또는 시간 초과 → 일부 자원만 회수 / 또는 실패 정산(데모에선 단순화)

### 2.2 자원 (라이트)
미션 중 다루는 자원은 **최대 3종**으로 제한.

| ID | 이름(가칭) | 용도 |
|----|------------|------|
| `pulp` | 펄프/광석 조각 | 기본 보상·강화 재료 |
| `bloom` | 블룸/결정 | 고급 보상 |
| `relic` | 유물(미션 목표용) | 회수 미션 전용, 가방 슬롯 차지 |

인벤 = **미션 가방 하나**. 복잡한 장비창 없음.

---

## 3. 4역할 디자인

공통: **이동(WASD) · 조준(마우스) · 대시 · 줍기**

역할마다 **고유 액션 2개**만.

| 역할 | 판타지 | 액션 A (주) | 액션 B (쿨) | 없으면 |
|------|--------|-------------|-------------|--------|
| **드릴러** Driller | 길을 연다 | 드릴 채굴(홀드) | 돌파/광역 파기(짧은 채널) | 우회가 길고 막힌 길이 많음 |
| **스카웃** Scout | 어둠을 연다 | 플레어/횃불 투척 | 빠른 대시·표식 | 시야가 좁아 위험·느림 |
| **엔지니어** Engineer | 공간을 만든다 | 임시 발판/다리 | 간이 터렛 | 틈·낭떠러지에서 막힘 |
| **거너** Gunner | 적을 지운다 | 중화기(지속 사격) | 짧은 방어막/넉백 장판 | 적 압박에 취약 |

### 3.1 솔로 보정
- 솔로: 선택한 역할 + **보조 드론 1기** (빛 / 채굴 보조 / 사격 중 하나, 미션 시작 시 고정).
- 또는 미션 프리셋에 “솔로 빌드”로 약화 적·자동 횃불 소량 지급.

**데모 구현 (M1):** 역할별 고정 1모드. LAN 코옵에서는 비활성.

| 역할 | 드론 | 보완 축 |
|------|------|---------|
| 드릴러 | 조명 | 스카웃 시야 |
| 스카웃 | 채굴 | 드릴러 파기 |
| 엔지니어 | 사격 | 거너 제압 |
| 거너 | 채굴 | 드릴러 파기 |

### 3.2 밸런스 원칙
- 역할 간 **딜 차이로 승부하지 않음**.  
  드릴러가 전투를 못 해도, 거너가 채굴을 못 해도 **미션은 깨지게** (느릴 뿐).
- PvE만. 역할 락(한 미션에 동일 역할 중복)은 코옵 시 옵션.

---

## 4. 미션 타입 (콘텐츠 최소 세트)

데모·얼리에서 **3종만**.

| 타입 | 목표 | 실패 조건 예시 |
|------|------|----------------|
| **채취** | 지정 광맥/자원 N개 확보 후 탈출 | 전멸 / 시간 초과 |
| **회수** | 유물 1개 픽업 → 탈출까지 운반 | 유물 운반자 사망 시 드롭 |
| **소탕** | 네스트/미니보스 처치 후 탈출 | 전멸 |

공통: **탈출**이 반드시 마지막 비트. (DRG의 “살아서 나가기”)

---

## 5. 월드 & 비주얼

### 5.1 표현
- 탑다운 2D, 타일 맵, Core Keeper식 **청키 암반 + 결정 + 웜 랜턴**.
- **타일 LOS + FoW**: 벽 너머 완전 어둠, 탐색 잔광, 횃불/플레어로 시야 확보.

### 5.2 바이옴 (본편)
초기 1개(퍼플 땅굴) → 이후 2~3개만 추가.  
바이옴마다: 바닥/적/광물/위험 1개(예: 도트 장판)만 바꿔도 충분.

**데모 구현 (M3):**
| 바이옴 | 비주얼 | 위험 |
|--------|--------|------|
| 퍼플 땅굴 | 딥퍼플 암반 (기존) | 없음 |
| 청록 염굴 | 쿨톤 청록 암반·적 틴트 | 염수 장판 DoT |

### 5.3 설치물
- **횃불/플레어**: 스카웃·공용 소모품.
- **발판**: 엔지니어.
- 영구 베이스 건축은 **본편 후반 또는 제외**. 데모에는 없음.

---

## 6. 전투 & 위협

- 적 수 적게, 패턴 단순 (추격 / 접촉 공격 / 원거리 1종).
- **울음·발소리**로 압박 (이미 프로토에 근접).
- 보스: 본편에서 미션 타입 “소탕”의 상한. 데모는 **엘리트 1마리**로도 충분.

---

## 7. 메타 진행 (얇게)

데모: **메타 없음** 또는 클리어 횟수만 표시.

본편(선택):
- 미션 보상 → 역할별 **스킨/소모품 언락** 정도.
- 스킬트리·농장·자동화는 넣지 않음.

---

## 8. 멀티플레이

| 단계 | 범위 |
|------|------|
| 데모 | **솔로**가 기본. **LAN 코옵**은 메인 메뉴의 테스트 항목으로만 |
| 프로토+ | 2인 같은 맵 동기화 (현재 `coop/` MVP) |
| 본편 | 2~4인 드롭인 코옵 |

코옵을 데모 성공 조건에 **넣지 않는다**. 코어루프(역할·목표·탈출)가 솔로로 재미있어야 함.

---

## 9. 재미 검증 데모 씬 (우선 제작)

### 9.1 목적
본편 전에 **코어루프가 재미있는지**만 검증.

> “역할 고르고 → 파고/비추고/싸우고 → 목표 깨고 → 탈출했을 때  
> 한 판 더 하고 싶은가?”

### 9.2 데모에 넣는 것 (Must)
1. **역할 선택 UI** (4버튼) — 선택에 따라 도구/스킬만 교체  
2. **미션 1판** (맵은 기존 퍼플 땅굴 생성기 재사용)  
3. **목표 1개** — 기본: **채취 N개 후 탈출**  
4. **LOS/FoW + 횃불/플레어**(스카웃)  
5. **드릴**(드릴러) / **총·제압**(거너) / **발판 1종**(엔지니어)  
6. **적 소수** + 간헐 울음  
7. **탈출 존** + 클리어/실패 결과 화면  
8. 한 판 **10분 타이머**(선택, 켜고 끌 수 있게)

### 9.3 데모에 넣지 않는 것 (Must not)
- 크래프트, 스킬트리, 마을 육성  
- 진짜 온라인 코옵  
- 다중 바이옴, 대형 보스  
- 파라미터 튜닝 패널 전부(개발자용은 숨김/토글)

### 9.4 데모 성공 지표 (플레이테스트)
플레이 3~5회 후 질문:
1. 역할 차이가 느껴졌는가? (예/아니오)
2. “탈출”이 긴장감을 줬는가?
3. 한 판 길이가 짧/적당/긴가?
4. 한 판 더 하고 싶은가? (1~5)

**통과 기준(초안):**  
역할 차이 체감 ≥ 70%, 한 판 더 ≥ 3.5/5, 길이 “적당” 비중 높음.

### 9.5 데모 기술 방침
- 기존 `tunnel-explorer-lab.html`을 **포크**해 `tunnel-crew-loop-demo.html`로 제작.
- 검증 통과 후 Unity/본편 엔진 이전을 검토 (지금은 루프가 우선).

### 9.6 데모 화면 흐름
```
[메인 메뉴]
  ├─ 솔로 미션 → [미션 타입] → [바이옴] → [역할]
  │              → [인게임] → [탈출 성공/실패] → …
  └─ LAN 코옵 (테스트) → [방 로비] → 채취 · 퍼플 → …
```
